# 场景包预览工具

把整个文件夹放在任意位置，双击「打开场景包预览.command」。浏览器会打开本机预览页。选择任意一个含 scene.json 和模型的场景包即可使用。关闭启动窗口可停止预览。

预览运行时只使用本文件夹内已构建的网页和 Node.js。请使用桌面版 Chrome 或 Edge，在选择文件夹时允许读写。「校验并保存」会直接更新所选文件夹里的 scene.json。校验或写入失败时，画面保留上一次已应用的配置。

项目中的预览界面源码位于 src，场景渲染、配置校验和音景播放与主项目共用。安装主项目依赖后，在预览工具目录运行 `npm run build` 可重新构建网页。

打开「3D版Loft」后，可在画面左下角切换七个机位，并通过画面上的主题下拉框切换场景包提供的日间、夜间、雨景和低光主题。开启「场景声音」即可试听当前主题。右侧「结构化编辑」将物件、机位与落点、灯光与画面、声音等配置分区显示。修改后点「校验并保存」，画面会应用新配置。新增配置项可使用「原始 JSON」，格式见 [场景制作格式](场景制作格式.md)。

## 保存时的视角

修改物件或操作范围后保存，会保留当前相机位置、朝向和缩放。修改初始位置、视野或朝向后保存，会切到新的应用视角。重新选择场景包也会使用该包的初始视角。

## 当前相机参数

| 参数 | 当前值和来源 | 是否适合按场景配置 |
| --- | --- | --- |
| 初始位置和视野 | scene.json 的 `camera.position` 和 `camera.fov`。初始视野须在 30–100° | 已支持 |
| 初始朝向 | scene.json 的 `camera.yaw` 和 `camera.pitch`，默认 0 和 −0.08 弧度 | 已支持 |
| 左右环顾范围 | `camera.limits.yaw`，默认 −0.85 至 0.85 弧度，约 −49° 至 49° | 已支持 |
| 上下环顾范围 | `camera.limits.pitch`，默认 −0.5 至 0.45 弧度，约 −29° 至 26° | 已支持 |
| 滚轮视野范围 | `camera.limits.fov`，默认 45–85°，可在 30–100° 内设置 | 已支持 |
| 拖动和滚轮灵敏度 | 每像素 0.003 弧度，每个滚轮 deltaY 单位 0.025° | 更适合放在全局偏好 |
| 近远裁剪距离 | 近裁剪距离为 0.1，远裁剪距离默认 150，可用 `camera.far` 覆盖 | 特别小或特别大的场景才需要覆盖 |
| 自由视角初始位置 | 预览器围绕房间模型的位置，以房间宽度估算观察距离，宽度取值限制为 2–60 | 需要固定外观展示镜头时可考虑 |
| 自由视角操作范围 | 预览器使用控件默认值。水平方向可环绕，极角为 0–180°，距离无额外上限；滚轮改变相机到目标的距离 | 可继续作为预览器设置 |

三项范围均为可选字段，使用 `[最小值, 最大值]`。初始视角可以设在操作范围之外，环顾或滚轮操作时会按对应范围限制。省略某项时使用表中的默认值。
