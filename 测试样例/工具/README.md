# 重新生成与校验

现有样例已经生成，不必运行工具即可使用。依赖安装到独立Python环境：`pip install -r requirements.txt`。本次额外编码库放在临时目录 `/private/tmp/cyber-fixture-deps`，清理临时目录不影响已生成素材；以后运行时可以在自己的虚拟环境安装同样依赖。

在项目根目录顺序执行：生成样例.py → 补充样例.py → 补充版式.py → 修正文稿字体.py → 校验样例.py。生成程序会覆盖本包同名文件，请先保存自己的测试记录和修改。程序不写应用资料库。

生成和视觉校验针对macOS字体路径；其它系统需要调整字体。Node契约校验 `node 测试样例/工具/校验应用契约.mjs` 使用当前项目生产解析器与备份仓库，并只在系统临时目录读写隔离数据。

本地AI服务使用标准库，不需要额外依赖；详见测试路线。生成器里的平台JSON和知识JSON为自定义测试契约，不是产品已支持的导入协议。
