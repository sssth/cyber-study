# 赛博书房本地测试样例库

先读 [测试路线](00_测试路线.md)，再按模块导入。所有内容均为原创合成测试资料；论文、电影、人物、日记和研究数值均属虚构，照片为绘制的测试风景图，音频为生成的低音量测试音，不是真实旅行照片或商业歌曲。素材可以长期用于本项目测试。

**不要把整个“测试样例”目录一键导入。** 正常、重复、异常、压力素材按测试步骤分开使用，否则失败与重复数量难以判断。不会自动改动现有收藏或用户数据库。

| 目录 | 内容与入口 |
| --- | --- |
| 01_地球仪 | 24张正常带GPS及拍摄日期的JPEG，四组旅程、八个城市；缺失元数据、零坐标、南西半球、日期线、极区、方向、HEIC/PNG/WebP、重复照片 |
| 02_学术 | 六篇相互关联的三页论文；修订版、完全重复、图像扫描及混合PDF；三份Word；RIS、BibTeX、CSL及文献笔记 |
| 03_电子书 | 六本六章MD、三本EPUB、三种中文编码TXT、长文和版本对照 |
| 04_音乐 | 九种真实编码音频，同专辑多曲、内嵌封面、无标签、Live/翻奏与改名重复 |
| 05_电影 | 30条虚构电影记录与30张海报，含同名不同年份、已看/想看、1—5星与独立公共评分、观影感想 |
| 06_日记便签 | 12篇虚构日记、透明贴纸、长便签、待办与打字机输入说明 |
| 07_知识库 | 跨论文、书籍、电影、音乐、日记的引用关系，标准检索答案与期望Markdown导出 |
| 08_批量压力 | 300张独立照片、120本独立书、60段音频（20文件夹）、1000条知识契约记录 |
| 09_异常样例 | 空文件、伪格式、损坏文件、加密PDF、超2MB图、超80MB照片；按说明逐项使用 |
| 10_接口模拟 | 两次同步、认证失败、限流、服务错误；自定义中性数据，不是官方API返回格式 |
| 11_备份恢复 | 符合当前地球仪格式的4条备份；缺原图/错版本备份；旧数据结构示例 |
| 12_场景包 | 自带GLB的14功能方块场景；重复ID、路径越界、非法视野、缺模型四种异常 |

“规划功能素材”不代表当前应用已支持导入。电影CSV/JSON、知识契约JSON、平台模拟JSON和旧数据JSON目前没有通用导入入口，**不要改名当作应用备份**。可按其中字段手工录入，或交给后续开发适配器使用。Zotero样例不是原生库备份，不能替代真实Zotero连接测试。

[逐条需求验收矩阵](00_逐条需求验收矩阵.csv) 从六份设计文档提取全部显式验收条目，保留来源章节和行号，执行状态初始均为“未执行”。它是验收记录表，不是功能通过报告。

[文件清单](样例清单.json) 包含相对路径、大小、SHA-256及部分元数据真值。[校验报告](校验报告.json) 记录实际完成的格式检查。校验成功不等于桌面应用端到端通过。

素材随项目保存在本目录；没有写入应用内，也没有连接个人平台账户。为了便于重测，移动或删除文件实验请先复制到本目录下新建的“临时测试副本”。
