# 测试路线与判断标准

## 一 先跑最小完整流程

1. 地球仪选择 `01_地球仪/正常照片` 文件夹：应扫描24张、首次成功24张。当前代码仍需用户确认地点，即使已读到GPS也不应自动成为已确认足迹。日期分布在2025年3—6月，不能显示为文件生成日期。
2. 再导入同一文件夹：应全部跳过重复。单独导入“改名但字节完全相同.jpg”也应跳过；“同景重新编码.jpg”哈希不同，当前可能新建，未来可作为视觉相似候选。
3. 书库导入 `03_电子书/正常`：6本、每本6章。分别在前两本第2章划线并写下相同标签“城市记忆”，然后到知识库筛选、回跳。翻到末章，关闭并重开，检查进度。
4. 将 `02_学术/全文` 的6篇PDF导入当前书库，可测试文字提取与跨文档摘录。正式学术题录、原页批注、写作项目等功能完成后，改从学术入口导入。
5. 音乐选择 `04_音乐/正常`：9首、9格式、8—16秒。依次播放，拖动进度，测试顺序/随机/单曲循环、返回书房、切换列表、应用重启。当前实现用临时文件地址，重启后失效应记录为缺陷，不能判为素材损坏。
6. 电影按CSV手工添加M01—M06并上传对应海报。区分同名不同年份，分别写感想和标签；电影不能用虚构ID测试真实豆瓣链接获取。
7. 手工录入D01与D02日记、三条待办、一个长便签，附加透明贴纸。后续统一知识功能完成后，执行跨模块路线。

## 二 地球仪与照片

| 操作和素材 | 应观察的结果 |
| --- | --- |
| 八城市GPS | 杭州/上海/京都/巴黎/纽约/悉尼/开普敦/利马；经纬度真值见清单，不能把西经或南纬转为正数 |
| 只有时间、只有坐标、均无元数据 | 分别缺地点、缺时间、两者缺；系统不应将磁盘时间当成可信拍摄日期 |
| 零经纬度 | (0,0) 是合法坐标，不应被当作缺失 |

| 非法日期 | EXIF内容2025:13:40；应校验或提示修正。当前解析器只做格式匹配，可能暴露缺陷 |
| 方向6 | 图片原始竖幅、EXIF Orientation=6；显示应遵循方向元数据 |
| HEIC/PNG/WebP | 都是真实对应编码；当前仅JPEG读取EXIF，其余进入待确认。HEIC若系统不能解码，应进入失败清单 |
| 当前地理图浏览 | 全球/放大聚合/地点详情/相册前后切换/返回；三个相邻点检验聚合 |
| 日期筛选与地点搜索 | 筛选2025年3月；搜索杭州；查看重复日期、跨年与缺失日期的排序 |
| 分组旅程 | 文件夹名是建议分组，尚未写入应用旅程数据；实际建议后需手动确认、拆分、改名、重排 |
| 想去转足迹 | 先标记杭州想去，再导入杭州照片，检查是否提示转为已去过 |
| 删除与恢复 | 删除一张已确认照片→回收站→重启→恢复；恢复后位置、日期、说明保持 |
| 原件移动 | 只移动临时副本。当前地球仪复制原件，移动后预览仍应可用；对引用式音乐则应提示重定位 |
| 300张压力照片 | 实际字节各不相同。导入、聚合、筛选、暂停/继续（若支持）、浏览缓存与重启；记录耗时，不预设性能通过阈值 |
| 81MB照片 | 是带JPEG头的超限文件，导入前大小检查应拒绝；不用填满磁盘来测试存储不足 |

当前备份包含精确坐标，均为虚构公共城市坐标；隐私隐藏、粗化位置和可选备份范围仍须按需求验收。

## 三 学术闭环及跨文档证据

六篇论文是相互独立的虚构研究，不能把题名相近误判为同篇：

| ID | 第2页关键内容 | 用途 |
| --- | --- | --- |
| P01 | 安静步行8.2，静坐6.1，n=24 | 支持性证据 |
| P02 | 噪声步行5.9，静坐6.0，n=20 | 与P01条件不同的反例 |
| P03 | 地标帮助位置回忆，不推出词语记忆 | 测量指标差异 |
| P04 | 阅读正确率71%至78%，无随机分组 | 相关不等于因果 |
| P05 | 器乐7.0，静音7.1 | 音乐效果反例 |
| P06 | 当天记录保留更多时间线索 | 日记与回忆偏差 |

各PDF第2页有唯一 `ANCHOR-Pxx-RESULT`，第3页有 `ANCHOR-Pxx-LIMIT`。表1故意在各文中使用同一版式测试数值，不应将表1数据自动当作所有论文的主结论；主结论以上述句子为准。

- 先导入六篇RIS，再导入对应PDF；期望关联全文而非重复实体。反向顺序也应测一次。
- 导入BibTeX相同六条：不应再次新建六篇。题名、作者、年份关联应可确认；样例未伪造真实DOI。
- “重复与冲突.ris”包含原条目、同名改作者年份和缺失字段条目。前者去重；冲突与缺失信息需审核，不能静默覆盖人工编辑。
- P01完全重复改名应去重；v2扩大样本应保留为不同版本，原摘录8.2/6.1不可被0.4覆盖。
- `全文版式_双栏图表.pdf` 含双栏、柱形图、脚注与横向第二页；检查文字顺序、区域批注框和横向页面回跳。
- 图像PDF恰好2页，无文字层；混合PDF5页，前三页可提取，后两页需OCR。当前书库不支持OCR，明确拒绝或提示扫描件是可接受的现状，不是规划完成。
- OCR应找回 `OCR-ANCHOR-1`、`Memory and attention`、n=24，并显示识别来源。测暂停/重试/失败只重跑未完成页。
- Word有三份：论文附件、写作稿、格式保护稿。导入后检查标题表格；选P01与P02插入引用，换样式、删除一处引用、更新文末表，原稿哈希不变，仅副本改变。
- “测试作者年份.csl”用于自定义样式导入；生成两篇引文时作者年份与题录一致。该文件结构检查不替代CSL处理器的完整规范验证。
- 正式Zotero测试：在单独测试文献库导入本包RIS/PDF，再用产品连接该库。验证分类、附件、同一item key重复同步及本地修改冲突。JSON只供适配开发，不能直接恢复Zotero数据库。
- DOI/ISBN联网匹配、Word/WPS实时连接须在真实软件和授权环境验证。本包只提供文稿与冲突数据，不声称包含真实外部题录查询结果。

## 四 电子书

- MD六本分别6章、每章10个带编号段落。长篇每章45段，足以测试滚动、位置、选区、章节跨页和搜索；不是用一份短文本冒充整库。
- 三本EPUB各6章、34个段落、目录、封面和返回链接。目录、字号重排、书签恢复、同作品MD/EPUB关联需要后续EPUB支持。
- 中文TXT有UTF-8 BOM、UTF-16、GB18030；应正确解码中文、CR/LF与标点，不出现乱码。
- 完全相同MD应按哈希跳过；修订版在正文中将“旧车站”改为“新车站”，需要与旧批注位置分离。
- 设置未读/在读/已读、红心、评分、读完时间，返回书房再进入；新版状态未实现时按需求表记录，不自行改数据库。
- 外部书目占位→关联本地EPUB/MD→保留原评分、完成日期与笔记。用接口模拟的中性记录准备流程，不能直接作为微信读书或豆瓣官方导出。
- 120本用于分页/排序/搜索；唯一词 `BULK-BOOK-119` 应命中最后一本。
- 空TXT、损坏PDF、假EPUB与正常文件混选；单个失败不阻塞其它文件。扫描PDF只在支持OCR的入口测试成功路径。

## 五 音乐

- 正常目录共9首：MP3/WAV/FLAC/AAC/M4A/OGG/OGA/OPUS/WEBM。专辑“城市回声”，歌手“合成声景实验室”；MP3与FLAC附内嵌封面，部分容器可能不保留全部标签。
- 展示名优先文件名，不应被标签或网络候选静默改写。原创测试音在平台搜不到属于预期，可测未知状态；高置信度匹配需适配器模拟或真实授权歌曲。
- 同专辑归组1张唱片9曲；展开折叠、点击第5曲、暂停、切换视图、播放队列连续性。
- 无标签曲可播放且进入待确认；Live/翻奏不能单凭名称合并。重复目录MP3与第一首字节完全相同。
- 首次与再次同步模拟：新增003、更新001、002虽然远端消失但本地保留；人工封面、笔记、选择不可覆盖。JSON是中性契约，需映射实际适配器。
- 60段压力音频有20个文件夹，每段1秒，可测自动下一曲与列表，但无标签，不能据文件夹名称断言应用专辑自动归组正确。
- 当前文件夹导入可能不去重、标签未读取；应记录功能差距，不能将规划规则当作已有行为。

## 六 电影与跨媒介知识

电影数据有27条已看、3条想看；已看中4或5星共9条，适合默认高星预选。其余可手动选，想看应排除。个人星级与公共评分是独立字段。

- M01“归途”(1996)和M02“归途”(1997)不是同一实体，不要按标题误合并。
- 上传海报→手工修正→再次导入元数据，手工海报与长评应保留。
- 将一条感想编辑两次、取消一次、关闭重开；验证草稿、版本和知识库只同步一条最新版。
- 选P01/P02/P03摘录、B01划线、M01感想和A01音乐感受到项目“城市旅行与记忆”。建立N01→N02反例关系、N01→N03不同指标关系。
- 搜索“城市记忆”应跨媒体命中；搜索 `ANCHOR-P02-RESULT` 应回到对应文档页。语义搜索“走路能让我记得更牢吗”应优先相关论文，不能仅靠日记作科学结论。
- 问“步行一定能改善记忆吗”：答案应区分环境、指标，引用P01/P02/P03；问“持续十年效果”应报告证据不足。
- D01含唯一私密标记 `DIARY-PRIVATE-00`：本地可搜索，默认AI发送预览中不得出现。单次授权D01后，只发选定片段；新会话再检查默认排除。
- 取消一个候选来源后检查实际发送内容；普通AI回答不直接成为正式知识。保存选段、改写后需保留原回答、模型、来源与AI辅助标记。
- 删除来源副本后，历史摘录快照仍可读，原文回跳显示失效；恢复来源后重新关联。删除知识不能级联删原书。
- 导出单条/项目/对话，参照 `综合笔记_期望导出.md` 检查脚注与来源；再导出一次不应重复写入知识。
- 1000条知识契约数据用于未来批量装载器，检查唯一词 `LOAD-NOTE-0999`；当前没有导入器，不能直接拖入UI。

## 七 备份与恢复

在空的测试资料库中，选择 `11_备份恢复/地球仪_有效` 恢复：4条记录，2条正常已确认、1条已删除、1条待确认。再次恢复应新增0条。恢复后检查原图、缩略图与备注，并自行从应用导出一份再恢复。

错误版本和缺原图备份应拒绝，已有数据不变。普通书籍、学术和统一知识的备份格式尚未冻结，不提供冒充真实备份的压缩包；请先用本包素材建立数据，再由实际产品导出备份，用该备份验证恢复、迁移和回滚。旧数据JSON只提供隔离迁移测试输入，不能覆写个人现有存储。

## 八 其它书房功能与场景

- 日记：不同心情、中文长文、照片、日期筛选、关键词、编辑删除、重启；2MB以上PNG应明确拒绝，透明贴纸应保持透明。
- 便签：待办完成/取消、长便签、照片、拖动排列、删除、重新打开；窗口缩小时不丢内容。
- 打字机：按说明实际键入，混合正确/错误字符和中文输入法组合，保存未完成草稿再继续；完成作品分别下载、加入日记、加入便签。当前粘贴被禁止，文本仅供照录。
- 宠物/植物：从空状态建立，命名、切换品种、互动、浇水/抚摸、重启状态保持。无需外部文件，不能用伪造JSON取代UI交互。
- 场景正常包由14个功能方块组成，不是艺术场景。选择其scene.json或整个文件夹（按当前入口），点击各功能；方块按两排排列，ID与功能一一对应。
- 四个错误场景：重复ID、路径越界、视野120应被验证器拒绝；缺模型通过结构校验但加载时报错，不能让整个应用白屏。
- 灯光、雨、环境声、画质、快捷键、机位/漫游、返回、窗口尺寸、减少动态效果：在正常方块包和原项目现有完整场景中各测一轮，观察相同收藏数据不随场景丢失。

## 九 只能靠运行环境验证的部分

登录过期、真实平台授权、联网封面、地图瓦片、真实API计费、Word/WPS兼容、磁盘满、权限失败、进程中断、外接磁盘断开和低性能设备，不能仅靠静态素材证明。本包提供输入及下述本地模拟器；剩余条件需在隔离测试环境中控制。空状态请使用新测试资料库，不要清空个人收藏。

本地AI模拟器：在终端运行 `python3 测试样例/工具/本地AI模拟服务.py`，API地址填 `http://127.0.0.1:8765/v1`，密钥可填 `fixture-not-a-secret`，模型选 `fixture-ok`。换 `fixture-401` / `fixture-429` / `fixture-500` / `fixture-timeout` / `fixture-malformed` 可测错误；超时模式等待35秒，客户端超时设5秒即可。仅支持非流式聊天，不提供真实推理、嵌入或语义质量验证，不记录提示正文。完成后Ctrl+C停止。若当前应用不接受本地HTTP，这项等待开发接入，不能绕过配置校验。

每次测试记录：应用版本、素材组、预期数量、实际数量、失败原因、耗时、是否重启、截图位置。逐条需求矩阵中的“未执行”应在实际测试后改成“通过/失败/尚未实现/外部条件待准备”。
