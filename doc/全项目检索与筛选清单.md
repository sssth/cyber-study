# 赛博书房各页检索与筛选清单

核对日期：2026-11-27。范围为主应用的七个已登记内容功能、书房全局入口、个人知识库、关联面板、地图投影，以及这些页面内的局部选取器。以下按当前工作区的页面实现记录。表中“无”表示该入口没有独立筛选项。

## 1　搜索框怎样决定搜哪里

- **范围跟随前台页面。** 在书房主场景搜索时查全局目录；打开内容页后查该页。子面板可以接管同一个搜索框，例如从摘录列表打开批注后，搜索对象缩小到这条摘录的批注。每个范围保存自己的条件。普通收起会暂停过滤，重新打开会恢复。
- **普通列表按包含关系匹配。** 英文忽略大小写，字符先做 Unicode NFKC 归一化，例如全角 ＡＢＣ 可以用 abc 找到。空格分开的词必须全部出现，可以乱序、分布在不同可搜字段；英文双引号把一段文字作为连续短语。中文可以输入连续的一小段。没有按拼音、同义词、错字或语义相似度扩展的一般规则。
- **筛选可以单独使用。** 同时输入关键词、选择多个筛选维度时，所有生效条件取交集。下拉框每个维度选一个值。日期含起止当天；系统依次取记录日期、开始日期、完成时间、创建时间中首个有值的字段。带时区的 ISO 时间按本地日期比较。只有页面列出的筛选项可在该页直接选择。
- **计数取决于页面。** 搜索框有关键词且页面已上报计数时才显示数字。普通范围超过 99 显示 99+，单书阅读和地图浏览声明精确计数。纯筛选仍会改变内容。全文出现次数、记录条数、分组数的区别见下表。
- **定位条件另算。** 从目录、关系或旅途跳到某条内容时，可以附带记录 ID、歌单 ID、地点或旅途 ID。它们限制此次打开的结果，技术 ID 本身通常不参与关键词匹配。

## 2　全局目录能搜哪些字段

下表也供第 3 节的知识库和关联面板查阅。**每一行都包含目录标题和该条内容的标签**，右列列出额外字段。标题由内容类型生成或取原记录标题，必要时用正文开头或缺省标题。目录按类型和记录 ID 去重，通常排除已删除内容。

| 内容类型 | 标题之外可输入的内容 | 字段边界 |
|---|---|---|
| 书籍 | 作者、正文 | 普通关键词遵循书籍字段勾选 |
| 摘录 | 摘录原文、来源书名、章节标题 | 同一摘录归为一条；目录里批注另列 |
| 批注 | 批注文字、来源书名、记录的 text 字段（如有） | 章节标题也可搜；引文属于摘录 |
| 日记 | 正文、心情 | 目录标题由日记日期生成，因此日期也可能通过标题命中 |
| 便签 | 便签文字 | 图片便签可有“图片便签”目录标题；图中文字不做识别 |
| 待办 | 事项文字 | 完成状态由待办页筛选 |
| 电影 | 类型、国家或地区 | 年份、评分、评分来源、外部网址未列入关键词字段 |
| 歌单 | 无额外字段 | 歌单作为独立条目；不把成员曲名并入该条的关键词 |
| 曲目 | 歌手 | 不搜时长、平台名或用户备注 |
| 抄写作品 | 原文、章节标题、来源书名 | 原文与用户已键入文本分别保存；后者未列入关键词字段 |
| 记忆点 | 国家、省区、城市 | 经纬度和时间未列入关键词字段 |
| 旅途 | 无额外字段 | 旅途名称走标题；成员记忆点的文字不并入旅途 |

|---|---|---|

| 摘录与批注 · 列表 | 以一组摘录为单位，合并来源书名、章节、引文、摘录标签、组内各批注正文及批注标签。各词可跨这些字段；任一批注使整组满足条件即可返回，计数为摘录组数 | 摘录类型（高亮、划线、书签、不显示） |

## 字段与逻辑检索

输入 `/` 后，左列按优先级列出当前范围支持的运算符，字段空值 NONE 排在最后，右列列出当前可搜字段；摘录和批注的正文共用 text，电影出品地区使用 movie.region。公共属性只列一次并提示适用实体；同名的业务专属字段分别归入各实体。例如，`title` 统一查询书籍、歌单、曲目等实体保存的名称，`artist` 专属曲目。中英文界面均插入相同的属性名，先前的中文字段写法仍可使用。普通关键词仍按页面原有规则匹配。

全局搜索、知识库分组、全部条目和关系图谱支持后缀保留字 `RELATED`。例如，`杭州 RELATED` 返回直接命中的条目和它们在图谱中相连的一层实体。类型筛选作用于直接命中，关联结果可以跨类型。输入 `"RELATED"` 可搜索这个词本身。

字段后填文字，或选择 `NONE` 检查未填写。例：`city:NONE AND NOT country:NONE` 查找国家已填、城市尚空的记忆点。其他实体不会因没有城市属性而命中。引号里的 `"NONE"` 搜字面文字。空格连接条件等价于 AND；运算符从高到低依次为 RELATED、NOT、AND、OR，可用括号分组。日期、评分及固定状态沿用筛选框。单书和书写视图按当前文本标亮肯定词，纯排除条件没有可高亮的词。

### 哪些字段真的共用

- **全部实体**只有手动标签 `tags` 这一项检索能力。电影直接读条目标签；其他类型先读按类型和 ID 保存的单独标签，再回退到条目自带标签。两套本地存储此次都没有单独的标签键；开发版摘录记录与两套电影记录可见内嵌的 `tags` 属性。
- **多类共用**有 `title`（书籍、电影、歌单、曲目、记忆点、旅途、抄写作品、支持标题的便签）；`text`（摘录、批注、日记、便签、待办、抄写原文）；`bookTitle, chapterTitle`（摘录、批注、抄写作品）。`movie.region` 是电影出品地区，`region` 是记忆点行政区。这里按同一检索属性归并，搜索仍限定在当前页。
- **其余字段**按表中的实体归属。例如 `artist` 属于曲目；`author` 属于书籍。曲目中也观察到 `note` 属性，但它没有进入曲目的关键词范围，因而不会出现在曲目菜单里。
- **正文位置**由场景决定。单书阅读只在当前书文本中找位置；抄写时只搜当前原文；打字机选择来源书只搜书名、作者和标签。它们不会自动继承整个目录的字段集合。

### 可配置字段与条件查询

上文的逐页清单记录普通关键词的初始范围。书房菜单“搜索字段”可按实体修改普通关键词匹配的属性。当前可指定字段以该设置和实体页的斜杠菜单为准。日期、评分和固定状态也能直接写在查询中，原筛选按钮可与语句一起使用。书籍正文的普通关键词沿用各页原有全文范围；在实体目录明确使用 content: 可直接指定书籍正文。单书阅读和抄写原文继续按文内位置检索。

| 查询 | 含义 |
|---|---|
| `TYPE book AND readingStatus:reading` | 在读的书 |
| `score:FROM 0 TO 6` | 豆瓣评分在 0 到 6 之间，含两端 |
| `watchedOn:FROM 2021年1月1号 TO 2021-1-31` | 一月观影记录 |
| `photo:YES AND city:NONE` | 有图片且城市为空的记忆点 |
| `TYPE todo AND done:NO AND showOnBoard:YES` | 展示在板面的未完成待办 |

实体范围使用保留字 `TYPE`（例如 `TYPE book`），选择后列出当前范围支持的实体类型。旧写法 `type:book` 仍可读取。书房菜单的“搜索字段”只分公共字段和专属字段，公共在前。公共查询属性为 tags、title、text、photo、createdAt、updatedAt，按实体实际支持情况显示。photo 统一判断图片存在性。仅在同一业务内复用的属性归入专属字段。斜杠菜单公共字段只列一次并提示适用实体，专属字段按实体分别列出；例如歌单和曲目的 provider 分别插入 playlist.provider: 和 music.provider:。

上述历史存储清单中的电影 review、旅途 note、记忆点 caption、歌单 description、曲目 note 现统一迁入 text，界面沿用各自含义。它们在未修改默认设置时通过 text: 显式查询。来源书籍 ID 不再作为搜索条件，来源书名和章节仍可指定。

右侧筛选会直接改写输入框。知识库选择书籍生成 `TYPE book`，影片评分上下限生成 `score:FROM 0 TO 6`。单侧边界也可独立使用。在输入框编辑同一条件会同步更新筛选；包含 OR 的分支保留在语句里。
