# 赛博书房各页检索与筛选清单

核对日期：2026-11-27。范围为主应用的七个已登记内容功能、书房全局入口、个人知识库、关联面板、地图投影，以及这些页面内的局部选取器。以下按当前工作区的页面实现记录。表中“无”表示该入口没有独立筛选项。

## 1　搜索框怎样决定搜哪里

- **范围跟随前台页面。** 在书房主场景搜索时查全局目录；打开内容页后查该页。子面板可以接管同一个搜索框，例如从摘录列表打开批注后，搜索对象缩小到这条摘录的批注。每个范围保存自己的条件。普通收起会暂停过滤，重新打开会恢复。
- **普通列表按包含关系匹配。** 英文忽略大小写，字符先做 Unicode NFKC 归一化，例如全角 ＡＢＣ 可以用 abc 找到。空格分开的词必须全部出现，可以乱序、分布在不同可搜字段；英文双引号把一段文字作为连续短语。中文可以输入连续的一小段。没有按拼音、同义词、错字或语义相似度扩展的一般规则。
- **筛选可以单独使用。** 同时输入关键词、选择多个筛选维度时，所有生效条件取交集。下拉框每个维度选一个值。日期含起止当天；系统依次取记录日期、开始日期、完成时间、创建时间中首个有值的字段。带时区的 ISO 时间按本地日期比较。只有页面列出的筛选项可在该页直接选择。
- **计数取决于页面。** 搜索框有关键词且页面已上报计数时才显示数字。普通范围超过 99 显示 99+，单书阅读和地图浏览声明精确计数。纯筛选仍会改变内容。全文出现次数、记录条数、分组数的区别见下表。
- **定位条件另算。** 从目录、关系或旅途跳到某条内容时，可以附带记录 ID、歌单 ID、地点或旅途 ID。它们限制此次打开的结果，技术 ID 本身通常不参与关键词匹配。

## 2　全局目录能搜哪些字段

下表也供第 3 节的知识库和关联面板查阅。**每一行都包含目录标题和该条内容的标签**，右列列出额外字段。标题由内容类型生成或取原记录标题，必要时用正文开头或缺省标题。目录按类型和记录 ID 去重，通常排除已删除内容。

| 内容类型 | 标题之外可输入的内容 | 字段边界 |
|---|---|---|
| 书籍 | 作者；开启书籍全文后另查整本正文 | 默认只搜书名、作者和标签 |
| 摘录 | 摘录原文、来源书名、章节标题 | 同一摘录归为一条；目录里批注另列 |
| 批注 | 批注文字、来源书名、记录的 text 字段（如有） | 被批注的引文 quote 和章节标题没有列入批注的检索字段 |
| 日记 | 正文、心情 | 目录标题由日记日期生成，因此日期也可能通过标题命中 |
| 便签 | 便签文字 | 图片便签可有“图片便签”目录标题；图中文字不做识别 |
| 待办 | 事项文字 | 完成状态由待办页筛选 |
| 电影 | 类型、国家或地区、观看状态 | 年份、评分、评分来源、外部网址未列入关键词字段 |
| 歌单 | 歌单说明 | 歌单作为独立条目；不把成员曲名并入该条的关键词 |
| 曲目 | 歌手、专辑、风格 | 不搜时长、平台名或用户备注 |
| 誊写作品 | 原文、章节标题、来源书名 | 原文与用户已键入文本分别保存；后者未列入关键词字段 |
| 记忆点 | 地点文字、国家、省区、城市、说明、文件名 | 经纬度和时间未列入关键词字段 |
| 旅途 | 描述、备注 | 旅途名称走标题；成员记忆点的文字不并入旅途 |

## 3　跨功能入口

| 页面／视图 | 搜索对象、匹配条件与结果 | 可选筛选 |
|---|---|---|
| 书房主场景 · 全局搜索 | 查第 2 节全部类型。有关键词或筛选时列结果；标题与整条输入完全相同者排前，其余按标题排序。首次展示最多 40 条，计数覆盖全部命中 | 内容类型；书籍正文默认仅元数据，可选包含全文 |
| 个人知识库 · 条目列表／分类浏览 | 在同一目录中按第 2 节字段搜。分类改变呈现方式，共用条目范围 | 条目类型 |
| 个人知识库 · 关系图 | 先按目录字段选出命中节点，再补上与命中节点直接相连的节点以展示关系。图上节点数可能多于命中数；关系名称不作为关键词 | 条目类型 |
| 个人知识库 · 统计 | 搜当前统计布局中的分组名和指标名。命中组名保留整组；否则只保留名称匹配的指标。计数为保留的指标数 | 无 |
| 个人知识库 · 回收站 | 搜普通回收记录、已删除书籍、旅途和记忆点。用回收记录保留的字段按第 2 节匹配，计数为回收条目数 | 条目类型 |
| 关联面板 · 查看已关联 | 搜当前内容已关联的有效对象，使用对方的目录字段；多选内容时看共同关联的对象 | 类型；可选包含书籍全文 |
| 关联面板 · 关联已有内容 | 搜允许建立关联的目录候选，排除已共同关联项；选中类别后再收窄。新建关联时使用搜索会切到已有候选 | 类型；可选包含书籍全文 |

**书籍全文的具体条件。** 全局和关联面板分别检查“全套关键词都能在元数据中找到”或“全套关键词都能在整本正文中找到”。例如作者只在作者栏、地名只在正文，两词组合仍可能搜不到。知识库条目列表、关系图和回收站没有提供这个全文开关。

## 4　书库、阅读、摘录

| 页面／视图 | 搜索对象和关键词条件 | 可选筛选／范围 |
|---|---|---|
| 全部藏书 | 查书名、作者、标签；同时把书籍正文解析成文本块，逐块检查。元数据匹配，或至少一个正文块独立包含全部词，就保留该书。显示命中片段，按书计数 | 阅读状态（待读、在读、已读）。通过限定书目入口打开时先限制书籍 ID |
| 展示书架 · 每一架 | 仅搜当前架上仍存在的书。使用与全部藏书相同的元数据和正文块匹配。按架上命中的书计数 | 阅读状态（待读、在读、已读） |
| 展示书架 · 选书上架 | 回到藏书候选中，沿用全部藏书的关键词与正文块规则；候选再排除本次标记为已使用的书。最多选 10 本；搜索框计数沿用排除前的藏书匹配数 | 阅读状态（待读、在读、已读） |
| 单书阅读 · 滚动／分页 | 只在当前书解析后的文本块找每个词或引号短语的出现位置。任一词出现即可高亮，按位置计数。例：输入“雨 杭州”，只有“雨”的段落也能保留 | 保留上下文可选句、段、章，默认段；选择章会展开包含命中的章节 |
| 摘录与批注 · 列表 | 以一组摘录为单位，合并来源书名、章节、引文、摘录标签、组内各批注正文及批注标签。各词可跨这些字段；任一批注使整组满足条件即可返回，计数为摘录组数 | 摘录类型（高亮、划线、书签、不显示） |
| 摘录详情 · 此摘录的批注 | 只查该摘录下有批注文字的记录，使用批注标题（如有）、标签、text、批注文字、来源书名。带具体批注 ID 打开时再限该条。计数为匹配的批注数 | 无 |

例如一本书第一段写“杭州”，第二段写“雨季”，书名、作者及标签都没有这两个词。输入“杭州 雨季”时，全部藏书和展示书架都要求同一正文块包含两词；打开单书会分别高亮两处。

## 5　日记、便签、电影、打字机

| 页面／视图 | 搜索对象和关键词条件 | 可选筛选／范围 |
|---|---|---|
| 日记 · 阅读 | 在日记记录的正文、心情、标签及已有标题中匹配，按篇计数；翻页在命中篇目中进行。正文另行标亮，因此只由标签或心情命中的篇目可以没有正文高亮 | 起始日期、结束日期 |
| 日记 · 书写 | 只找当前草稿正文中各词的出现位置；高亮重叠范围会合并，计数为高亮范围数 | 无 |
| 便签板 · 板面 | 在允许展示在板面的便签与待办中搜文字、标签及已有标题。图片便签只按文字字段和标签参与搜索 | 类型（便签／待办）、待办状态（未完成／已完成）；选择待办状态通常只剩待办 |
| 便签板 · 便签列表 | 搜所有非待办便签，包括未放上板面的条目；字段同上 | 沿用板面筛选，另可选是否在板上展示 |
| 便签板 · 待办列表 | 只搜待办的事项文字、标签及已有标题 | 沿用板面筛选，另可选是否在板上展示 |
| 电影收藏 | 搜片名、自定义标签、类型、国家或地区、观看状态。按影片计数 | 观看状态（想看、在看、看过）、评分上下限、个人评分上下限、观影起止日期。各范围可只填一端，包含边界。指定范围时，缺少相应值的影片不匹配 |
| 打字机 · 未完成／已完成作品库 | 作品标题、标签、原文、来源书名、章节标题。列表先限当前完成分组，再应用条件。按当前分组的命中作品计数 | 无 |
| 打字机 · 来源书选择 | 搜可选书籍的书名、作者和标签，按书计数 | 无 |
| 打字机 · 正在誊写 | 搜当前选定原文中任一词或短语，高亮并数出现次数。按原文字面忽略大小写匹配；输入区已打出的字不参与 | 无 |

## 6　留声机与音乐选择器

| 页面／视图 | 搜索对象和关键词条件 | 可选筛选／范围 |
|---|---|---|
| 歌单与曲目 | 默认分别检查歌单名＋歌单标签，以及单首曲名＋歌手＋曲目标签。歌单命中会带出符合平台条件的成员；只有曲目命中时，在相应歌单内显示命中曲目。搜索框按去重曲目 ID 计数，空歌单即使命中也不增加曲数 | 搜索依据可选曲名、歌手名、歌单名。前两项只匹配对应字段；歌单名模式仍匹配歌单标签。另可按已有曲目的平台筛选 |
| 唱机播放页 | 共用音乐搜索范围和上述曲目计数；播放页供其他命令使用的当前对象是正在播放的曲目 | 沿用音乐范围 |
| 创建歌单／从现有曲目选歌 | 在本地曲目候选中按音乐搜索条件匹配，默认字段含曲名、歌手和手动标签 | 沿用音乐搜索依据和平台 |
| 平台歌单导入 | 在平台已列出的歌单中搜歌单标题，并核对所选平台；此处不按曲名或歌手搜索远端曲库 | 沿用音乐框关键词、平台；搜索依据选项不参与这份候选匹配 |

同一首歌可以在全局按专辑或风格找到，而在留声机里需要用曲名、歌手或标签找。歌单说明同样属于目录字段，未加入留声机的歌单名匹配。

实现入口：[音乐主界面及选歌](../src/features/music/MusicPlayer.jsx) · [平台歌单](../src/features/music/MusicSources.jsx) · [音乐目录字段](../src/features/music/definition.js)

## 7　地球仪、地理目录与地图投影

| 页面／视图 | 搜索对象和关键词条件 | 可选筛选／范围 |
|---|---|---|
| 记忆点管理 | 搜记忆点名、标签、地点、国家、省区、城市、说明、文件名。按点计数。从地点或旅途跳入时保留来源范围，到访状态由页面分栏展示 | 起始日期、结束日期 |
| 旅途管理 | 搜旅途名称、标签、描述、备注，按旅途计数。日期优先使用记录日期或旅途开始日，不按起止行程与查询区间的重叠判断 | 起始日期、结束日期 |
| 编辑旅途 · 选成员 | 复用旅途页条件，但候选对象改为有效记忆点。因此同一词在后台旅途卡片查旅途描述，在成员候选中查点名、地点、说明等记忆点字段 | 沿用旅途页日期条件 |
| 地球浏览 · 按记忆点（默认） | 用记忆点字段匹配，地图和点列表据此更新；旅途列表保留有效旅途。计数为匹配点数 | 搜索依据；若已进入国家／省区，再限该区域 |
| 地球浏览 · 按旅途 | 用旅途名称、标签、描述、备注匹配旅途，取命中旅途的成员点，再与区域条件相交；成员点本身无需含该词。计数仍按点 | 搜索依据选“按旅途”。浏览模式不应用管理页的日期、到访状态 |
| 地球浏览 · 地理目录 | 同一输入还驱动地名候选。国家／行政区查名称、英文名，并处理“中国”别名；城市查名称、ASCII 名、别名。按整条输入做包含匹配。无词时显示当前层级的下级区域 | 导航所在层级；地名候选与记忆点走两条匹配路径 |
| 记忆点编辑 · 离线城市 | 表单输入仅查城市名称、ASCII 名、别名；忽略大小写，整串包含，最多给出 10 条。选中后填入城市、国家、省区及坐标 | 无 |
| 从其他页面“在地球仪上显示” | 先读取地图数据，并把来源结果关联的记忆点作为初始选中点。投影内复用上述地球浏览、记忆点、旅途入口，并使用独立搜索范围；初始高亮不限制整个地图的可搜对象 | 随投影内当前视图切换，同相应地球仪页面 |

区域判定优先按经纬度是否落入边界。缺坐标时才用国家／省区名；有坐标而边界几何尚不可用时，该点不能通过区域判定。另有一个计数细节：普通地图和投影注册了不同搜索范围，但浏览组件固定向普通地图范围上报点数，因此投影浏览的搜索框可能收不到自己的命中数。

## 8　其他界面与核对边界

公共操作选择器在动作超过 12 个时提供独立过滤框，按翻译后的动作名称做忽略大小写的整串包含匹配。设置、快捷键配置、使用手册、场景校准等未注册各自的内容检索字段；书房全局搜索也有单独的启用条件。快照等结果应用消费前台页面已匹配的实体。以上均不另算一套内容索引。[操作选择器](../src/features/ContentCommands.jsx) · [应用入口](../src/App.jsx)
