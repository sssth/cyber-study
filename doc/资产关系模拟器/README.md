# 资产关系模拟器
直接用浏览器打开 index.html 即可，或在本目录运行 `python3 -m http.server 4178` 后访问 http://localhost:4178 。无构建、无网络依赖。

体验：选择西湖记忆点 → 检查两个上级和关联内容 → 新建日记 → 添加上级/下级/关联 → 查看字段与 JSON → 编辑 JSON 增加专属字段 → 定义新类型。

只使用独立 localStorage 键 cyber-asset-simulator.v1，不读写主项目用户数据。初始示例只用于模拟；刷新保留已保存数据。导出包含类型、内容、关系、空附件容器。附件暂不提供上传；无文件导入、云同步、图谱拖动及真实音频播放。撤销保存最多 30 次当前会话操作。

测试：`node --test model.test.cjs`。

验证记录：Electron 独立浏览器窗口通过创建、包含连接、无效 JSON 提示、删除、撤销、刷新持久化、390px 窄屏无页面溢出检查；关系模型 2 项测试通过。静态 UI 审计无法识别本工具的外置 onclick 绑定与事件委托，仍报告 actionless-button；这些控件已在 app.js 绑定，核心流程已运行验证。内嵌浏览器预览连接超时，可使用外部浏览器或直接打开 HTML。

## 复杂样例
点击顶部“加载复杂样例”：追加 31 个内容、43 条关系（13 条包含、30 条关联），覆盖 11 种类型；保留现有条目，可撤销，重复点击不会重复追加已有样例。若主动删掉样例或关系，重新加载会补回缺失项。所有文字、歌曲、影片均为模拟数据，不含真实媒体文件。

推荐观察：
- **断桥 · 日落与晚风**：两个上级，连接日记、歌曲、摘录、影片和待办。
- **一天里的湖与山**：两个直接关联地点，自身 location 仍为空。
- **旅途结束后的整理**：自身地点为上海，关联地点为杭州、苏州，显示两种含义的区别。
- **江南 · 秋日旅行总集**：总旅途 → 城市旅途 → 记忆点，三层包含。
- **湖面回声 · 示例曲**：两个歌单共用一首歌，并与记忆点、日记关联。
- **旅行不只发生在目的地**：已加星、两条内部批注、书籍精确定位；另一摘录未加星且无批注。
- **下一次出发 · 空歌单**、**还没写完的一页**、**一个尚未分类的念头**：空集合、空正文、独立节点。
- **车窗外 · 未定位的片刻**：无地点与坐标；**天平山 · 下次再去**：想去状态。
- 影片有想看/在看/看过，待办与抄写均有完成/未完成状态。

加载后默认聚焦断桥与直接连接。切换“全部内容”看全图，大图滚动查看；侧栏搜索仅筛选内容列表。样例覆盖目前的主要内容状态与关系结构，并不声称穷举任意类型组合或存储故障。

## 当前版本：空白搭建与自由画布
当前入口不再加载基础或复杂样例，已移除“加载复杂样例”按钮；上述样例说明为历史记录。首次升级会先备份旧模拟数据到 `cyber-asset-simulator.v1.before-empty-start`，再移除带复杂样例标记或与初始示例完全匹配的条目及其连接，保留用户内容。修改过的无标记初始条目不会猜测删除。

滚轮以鼠标位置为中心缩放（20%–300%）；也可用 + / − / 100% / 适应全部。拖动画布空白处平移，拖动节点调整位置，连线跟随。聚焦节点后可用方向键移动。视角与位置保存在 layout 中，不属于内容公共字段；刷新保留。节点移动可以撤销。最新浏览器验证使用 canvas-test.cjs，旧 browser-test.cjs 针对历史示例入口，不再适用于空白启动。

## 直属与包含
紫色箭头 direct 为直属，蓝色箭头 contains 为包含，绿色虚线 related 为关联。书籍可有直属摘录和抄写作品，摘录可有直属批注；每个子项最多一个直属上级，可同时被多个集合包含。关系区域分别显示直属上级、直属下级、包含我的集合、我包含的内容、关联内容。既有合法类型的包含关系可用“改为直属”转换；不自动迁移用户关系。上下级联合检查循环。实验室尚不根据直属连接打开真实书籍，定位字段与媒体仍为模拟。

## 当前关系选择限制
规则已应用到方向和目标选择器，无法选择不合法目标。包含只开放旅途→记忆点、歌单→歌曲；关联禁止同类型、自己、重复及已保留给直属/包含的类型组合。历史关系不会自动删除，不合法的关系卡显示原因，并提供可用的转换入口。自定义类型仅开放跨类型关联。

当前验证命令：`node --test model.test.cjs rules.test.cjs`；浏览器验证 `rules-browser-test.cjs`、画布验证 `canvas-test.cjs`。历史 browser-test.cjs、direct-test.cjs 的旧关系规则预期不再适用。
