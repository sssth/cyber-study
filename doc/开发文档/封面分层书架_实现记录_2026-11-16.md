# 封面分层书架

已实现：
- 默认全部书籍以封面、层板展示，宽屏每层 4–5 本，窄屏两本；保留统一搜索、导入、阅读、删除与内容右键入口。
- 展示书架一复用 shelf 模型，展示书架二复用 F26 模型；保留唱片机、影碟机、耳机、石雕、玻璃球及水晶，排除原装饰书组。
- 分别提供 7 / 10 个陈列位，点击三维编号或下方选书按钮操作；支持更换、移走、同架去重、跨架复用及本地恢复。
- 有图片附件时取首图作封面，无图片时使用书名与作者生成封面；不会自动联网寻找封面。
- 本次陈列只影响书库展示页，不同步场景原件；移走不删除书籍、正文或摘录。

- 修复模型加载提示在 Suspense 中使用 Html 导致的卸载异常；改为外层 DOM 加载提示，复测无该错误。

边界：当前为固定陈列位选择，不提供自由拖拽、自动抓取封面或场景书架同步。模型不可用时仍可使用下方列表选书和阅读。陈列只保存书籍 ID，不复制正文，不影响既有迁移保护。

## 加载优化

原因：展示页使用 30–50 MB 的原始 GLB；卸载后立即释放，重复打开重新解析。两座书架共享石雕、水晶，缓存必须按单个 URL 共享对象，不能以不同 URL 数组分别创建模型实例。

实现：
- scripts/build-shelf-previews.mjs 从既有 LOD 和 1024px 纹理生成 8 个独立 GLB。紧凑化顶点、索引，内嵌纹理，无原件或外部纹理依赖；原场景画质设置不变。
- 资源共 323.36 MiB → 37.22 MiB，减少 88.49%。previewFile 加入场景校验和打包清单，旧场景包无此字段时回退原模型。
- 预览按 URL 并行预加载，卸载后缓存 60 秒，重新使用取消释放，闲置到期释放。其他场景模型仍使用原释放策略。

验证：
- node --test src/reader/shelfPreview.test.js src/scenes/three/renderOptimization.test.js：8 项通过，覆盖内嵌资源、打包收录、紧凑索引、材质与边界保留、共享缓存、重入和过期释放。
- vite build 成功（既有大包体提示仍在）。
- Electron 本地开发预览独立测试窗口：首次书架一 1269 ms，首次书架二 641 ms，返回书架一 182 ms，返回书架二 144 ms。加载完成后等待两次动画帧；最终轮次构建并行运行，结果为本机测量，不保证其他机器同速。
- 模型请求数量累计 6、8、8、8：后两次切换未重复请求资源。最终轮次无应用运行错误，截图核对两座书架和摆件完整。
