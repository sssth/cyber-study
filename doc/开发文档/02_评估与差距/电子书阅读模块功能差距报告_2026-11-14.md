# 电子书阅读模块功能差距报告

核对范围为当前工作区源码，依据[电子书阅读模块需求 v1.0](../01_需求与设计/赛博书房电子书阅读模块需求文档_v1.0.md)和[项目功能差距与迭代可行性报告 §3.1](项目功能差距与迭代可行性报告_2026-11-14.md)。以下为代码核对结果，桌面打包版和实际交互待验收。

**已有基础**　MD、TXT、文字版 PDF 批量导入，保留原件并转换为 Markdown；支持章节切换、滚动与双页阅读、字号行距、全书进度、划线与多条批注，以及知识库原文回跳和 Markdown 导出。

| 功能 | 主要差距 |
| --- | --- |
| **EPUB 导入与书目版本** | 尚无 EPUB。当前按文件内容哈希去重，缺少 ISBN、版本匹配和书目与正文分离。同一本书的不同格式无法归到同一书目，无正文书目也无法单独上架。 |
| **PDF 原页与定位** | 已保存原 PDF 和重排正文，缺少原页查看、重排与原页切换，以及段落到原页的定位。图表、脚注和混合扫描页无法靠重排版完整查看。纯扫描件 OCR 属于需求明确排除的范围。 |
| **书架与阅读状态** | 当前以卡片展示进度和摘录数。缺少封面分层书架、「正在读／最新导入」分区、待读／正在读／已读状态、95% 已读确认和重读记录。主分类、红心、自定义书单也未落地。 |
| **阅读器设置与书签** | 当前可按章切换，缺少可展开的多级目录。普通滚动与双页翻页已具备，仿真翻页和独立左右滑动模式待补。缺少主题、字体、段距、页边距、阅读宽度、首行缩进和独立书签。 |
| **标注与阅读统计** | 已有划线和批注闭环。缺少划线样式、删除划线时处理关联批注、无划线的当前位置笔记，以及前台有效阅读计时、单次／累计时长和剩余时间估算。 |
| **搜索** | 现有书库正文关键词搜索和知识库摘录／批注筛选。缺少当前书内搜索、书内／书库／全局范围切换、跨资料统一索引和语义搜索。 |
| **外部书单** | 微信读书书单和豆瓣已读导入均未落地。缺少临时审核、确认入架、豆瓣四五星预选及待补正文。数据来源需要先确认可用授权或个人导出方式。 |
| **旧数据与空间入口验收** | 有旧 IndexedDB 迁移路径，缺少统一备份、回滚、逐项迁移报告和旧进度／批注验收。已有书库与知识库路由，左右书架职责、左架下层热区与关闭阅读后视角恢复仍需桌面验收。 |

**建议优先顺序**　先做书目与正文分离及迁移保护，再做 EPUB、PDF 原页定位和阅读状态。之后补封面分层书架、书签与书内搜索。外部书单可单独验证数据入口。
