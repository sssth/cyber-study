# 唱片机功能差距简报

2026 年 11 月 14 日 · 对照需求 v1.0、项目迭代报告与当前源码

## 已实现

QQ 音乐和网易云支持登录、读取个人歌单、边导入边缓存、缓存后本地播放。同一张歌单重新导入可复用已缓存曲目，单首失败会列出原因。唱片机已有封面旋转、进度拖动、切歌、顺序回环／随机／单曲循环、场景快捷键、关闭面板后继续播放，以及重启后恢复上次的歌曲、所属歌单和进度。本地目前支持文件夹导入。

## 主要差距

| 优先级 | 当前与预期的差距 |
| --- | --- |
| P0 收藏保留（核心丢失路径已修复） | 重新导入只新增或更新成功曲目，保留旧曲目及原歌单顺序；退出账号不再删除未缓存曲目。每首缓存成功后立即保存，不必等整单完成。来源状态的细化展示仍属后续功能。 |
| P1 本地长期收藏 | 目前导入的文件夹只在本次打开期间有效。预期支持单个或多个文件及文件夹导入，重启后可播放，文件移动后可重新定位；还缺内嵌标签和封面读取、去重、自动匹配及待确认流程。 |
| P1 收藏浏览 | 目前是左侧播放器加右侧曲目歌单。预期是上方紧凑播放器、下方全宽列表，支持搜索、来源筛选、按专辑归组、分页及浏览位置记忆。需求中的「全部」是来源筛选，播放队列仍可沿用已明确的规则，按所选歌单或专辑播放。 |
| P2 专辑陈列 | 目前有播放中的唱片动效。预期还要有以专辑为单位的唱片架、专辑详情、唱片抽出与收回，以及可靠的跨来源专辑归组。 |
| P2 导入与同步 | 平台歌单导入和失败反馈已具备。还缺统一导入入口、收藏专辑入口、只新增或更新的手动同步，以及可回查的导入报告。两平台实际能读取的收藏范围和接口稳定性需要真实账号验证。 |

收藏保留修复已完成；本地持久化、全宽列表、唱片架陈列和跨来源匹配仍待后续安排。

本轮修复验证：合并逻辑回归测试、生产构建及隔离 Electron 窗口测试通过。覆盖平台少返回曲目、部分／全部缓存失败、空歌单、逐首保存、退出账号、页面重载、主动删除及共享歌曲保留，并复查缓存播放与进度拖动。使用模拟平台响应，未操作真实账号或真实收藏；未重新打包安装版。
