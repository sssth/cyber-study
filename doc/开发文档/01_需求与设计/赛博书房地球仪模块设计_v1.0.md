## 2. 设计结论

地球仪模块采用“沉浸式记忆地球”方案。它不是普通相册、旅行规划工具或无限风景推荐平台，而是赛博书房中的个人空间记忆装置。

用户在书房中点击实体地球仪后，镜头靠近地球仪，实体模型自然放大并过渡为全屏可旋转的 3D 地球。地球包含两个可独立开关的图层：

1. **我的足迹**：用户亲自导入、确认并珍藏的照片、地点和旅程。
2. **世界风景**：随应用提供的少量人工精选风景地点，保存完整来源与授权信息。

用户导入个人照片时，系统优先读取拍摄日期和地理信息，并自动提出旅程归组建议。旅程路线只在用户主动打开某次旅程时显示。用户对公共地点可以标记“想去”；以后导入该地点附近的个人照片时，可转为“已去过／我的足迹”。

3D 地球承担沉浸式浏览，平面地图只承担精确定位与整理。核心内容离线可用，联网仅用于更精确的地点搜索、地图补充和风景内容更新。

## 3. 产品定位与原则

### 3.1 个人记忆优先

个人足迹是地球仪的核心。世界风景只用于引导探索，不能用公共内容淹没用户自己的记忆。

### 3.2 精选而非堆积

地球仪只保存用户愿意长期珍藏的照片、地点和旅程，不追求替代系统相册，也不提供无限图片流。

### 3.3 沉浸浏览，轻量管理

主界面围绕旋转地球、靠近地点和展开照片设计。复杂整理操作进入独立的地图整理模式，不能在地球主界面堆积表格和按钮。

### 3.4 真实位置，不随机放置

任何照片光点都必须来自照片地理信息、地点搜索或用户地图选点。缺少位置的照片进入待确认区，禁止随机生成经纬度。

### 3.5 本地优先与隐私保护

个人照片、经纬度、旅程和文字默认保存在本地。核心浏览在断网时仍可使用。

### 3.6 来源与授权完整

世界风景照片必须将图片、摄影者、来源页面、授权类型和核验日期作为一个完整记录管理。

### 3.7 不自动污染个人知识库

照片和简短说明首先属于地球仪记忆库。只有用户主动写成并保存的旅行笔记，才进入个人知识库。

## 4. 目标与非目标

### 4.1 第一版目标

- 从书房实体地球仪自然过渡到全屏 3D 地球。
- 支持“我的足迹”和“世界风景”两个图层。
- 支持单张、多张和文件夹照片导入。
- 自动读取照片日期、经纬度和基础元数据。
- 支持地点搜索、候选确认和平面地图点选。
- 根据时间和空间距离提出旅程归组建议。
- 支持用户修改、拆分、合并旅程。
- 支持按地点和旅程浏览照片。
- 支持旅程路线按时间逐段播放。
- 支持公共地点“想去”及其向“已去过”的转化。
- 支持本地缩略图、重复检测和原图重新关联。
- 支持轻量旅行笔记进入个人知识库。
- 支持离线浏览和基础地点搜索。
- 支持回收站、恢复和引用影响提示。

### 4.2 第一版非目标

- 不替代系统照片管理软件。
- 不做酒店、机票、餐饮或路线规划。
- 不记录或推断实时位置。
- 不自动生成用户实际交通轨迹。
- 不接入无限在线风景图片流。
- 不提供热度榜、达人榜或算法旅游推荐。
- 不做公共社区、点赞和评论。
- 不把公共风景照片复制成用户个人照片。
- 不把每张照片说明自动写入个人知识库。
- 不做复杂的长篇旅行日志编辑器。

## 5. 总体信息架构

地球仪模块包含五个主要区域：

1. 书房空间入口。
2. 全屏 3D 记忆地球。
3. 地点照片卡与旅程播放。
4. 平面地图整理模式。
5. 导入与待确认中心。

主导航关系为：

```text
赛博书房
  └─ 点击实体地球仪
      └─ 空间转场
          └─ 3D 记忆地球
              ├─ 我的足迹
              ├─ 世界风景
              ├─ 地点详情
              ├─ 旅程播放
              ├─ 导入照片
              └─ 地图整理
```

## 6. 进入与退出转场

### 6.1 进入

1. 用户点击书房中的实体地球仪。
2. 书房其他可交互对象逐渐降低亮度和交互响应。
3. 镜头缓慢靠近实体地球仪。
4. 地球仪材质、边缘光和记忆点逐渐显现。
5. 实体地球仪在原空间位置放大。
6. 书房背景淡出，过渡为全屏 3D 地球。
7. 地球保持与实体模型接近的初始旋转角度，避免画面跳变。

### 6.2 退出

退出时执行反向动画：地球回到初始视角、缩回书房中的实体模型、书房光线与交互恢复。

如果用户正在编辑、导入或调整地点，退出前提示保存或放弃。普通浏览状态可直接返回书房。

### 6.3 减少动态效果

系统或应用开启“减少动态效果”时：

- 取消长距离镜头飞行。
- 使用短暂缩放和淡入淡出。
- 旅程路线不自动驱动镜头。
- 保留所有功能和内容，不因关闭动画而缺失入口。

## 7. 3D 记忆地球主界面

### 7.1 视觉中心

地球占据主要画面，界面控件保持轻量、半透明且不遮挡主要区域。默认背景延续赛博书房的深色氛围，但光点颜色与个人／公共图层有明确区别。

### 7.2 顶部控件

- 返回书房。
- 地点搜索。
- “我的足迹”图层开关。
- “世界风景”图层开关。
- 导入照片。
- 地图整理。

### 7.3 左下角状态

显示轻量统计：

- 去过的国家或地区数。
- 去过的城市数。
- 已形成的旅程数。
- 想去地点数。

统计不显示排名、完成率或制造打卡压力。

### 7.4 右下角控制

- 放大。
- 缩小。
- 回到全球视角。
- 自动旋转开关。
- 动态效果设置。

### 7.5 地球操作

- 拖动旋转。
- 滚轮或触控板缩放。
- 点击光点靠近地点。
- 双击空白区域放大。
- `Esc` 返回上一级。
- 方向键切换当前地点中的照片。

自动旋转默认速度缓慢。用户开始拖动、缩放或点击后立即停止，不能与用户争夺控制权。

## 8. 图层设计

### 8.1 我的足迹

只包含用户已经导入并确认的个人地点记忆。

显示内容：

- 温暖、明亮的地点光点。
- 地点照片数量。
- 关联旅程数量。
- 最近一次拍摄日期。
- 是否存在知识笔记。

### 8.2 世界风景

显示应用内置的人工精选地点，采用较弱、较冷的光点。公共地点不能在视觉上盖过个人足迹。

### 8.3 图层叠加

两个图层可以分别开关，也可以同时显示。相同地点同时存在个人足迹和公共风景时：

- 以个人足迹光点为主。
- 地点详情先显示个人内容。
- 公共风景放在独立标签页。
- 不把公共照片混入个人照片序列。

## 9. 地点聚合与层级

地点显示随镜头距离变化：

| 镜头层级 | 显示方式 |
| --- | --- |
| 全球 | 国家或大区域聚合点 |
| 区域 | 城市聚合点 |
| 城市 | 具体地点和地标 |
| 地点详情 | 照片、旅程与文字 |

聚合点显示地点数量或照片数量，但不能同时堆叠大量数字。镜头靠近后，聚合点平滑拆分为具体地点。

## 10. 地点搜索

### 10.1 搜索范围

搜索结果分组显示：

- 我的足迹。
- 想去地点。
- 世界风景。
- 尚未收录的普通地理位置。

### 10.2 普通地理位置

搜索到尚未收录的位置时，只将地球定位至该处，不自动生成收藏或足迹。用户可以随后选择“标记想去”或导入个人照片。

### 10.3 离线搜索

离线时支持国家、地区和主要城市搜索。更精确的街道、地标或小型地点搜索需要联网或通过地图选点完成。

## 11. 地点详情与照片卡

### 11.1 展开方式

点击地点后，镜头平滑靠近目标区域。地球保持可见并偏向一侧，照片卡以具有纸张层次的实体相片形式浮出。

### 11.2 个人地点卡

个人地点卡包含：

- 照片。
- 地点名称。
- 拍摄日期。
- 简短文字。
- 所属旅程。
- 标签。
- 原图状态。
- “写成记忆笔记”入口。

### 11.3 公共风景卡

公共地点卡包含：

- 精选照片。
- 地点名称。
- 简短介绍。
- 摄影者或机构。
- 来源页面。
- 授权说明。
- “想去／取消想去”。

### 11.4 多张照片

同一地点有多张照片时，可左右切换。照片数量较多时可以展开为沉浸式浏览，但不在主界面显示密集缩略图墙。

## 12. 个人照片导入

### 12.1 导入入口

支持：

- 单张照片。
- 多张照片。
- 整个文件夹。

第一版支持常见 JPEG、PNG、HEIC 和 WebP。具体格式以桌面端图片解码能力为准，无法解码的文件进入失败清单。

### 12.2 导入流程

```text
选择文件
  → 文件检查与重复检测
  → 读取拍摄时间和地理信息
  → 生成缩略图与预览图
  → 匹配地点名称
  → 提出旅程归组建议
  → 用户确认
  → 写入正式记忆库
```

### 12.3 元数据优先级

1. 照片内嵌拍摄日期与经纬度。
2. 用户之前对同一文件做过的确认记录。
3. 文件创建日期，仅作为候选时间并标记低置信度。
4. 用户手动输入或选择。

禁止把文件系统日期静默当成真实拍摄日期。

### 12.4 无地点照片

没有地理信息时，照片进入“待确认地点”。用户可以：

- 搜索地点。
- 从候选地点中选择。
- 在平面地图上点选。
- 批量为多张照片指定同一地点。
- 暂不处理。

未确认照片不显示在地球上。

### 12.5 重复检测

通过文件指纹、文件大小和基础图像特征识别重复导入。发现重复时显示已导入地点和日期，用户可以：

- 跳过。
- 重新关联原文件。
- 作为独立副本导入。

## 13. 本地图片存储

### 13.1 文件层级

- 原图：保留原文件引用，或根据应用既有策略复制到受管理的本地资料目录。
- 预览图：用于地点详情和沉浸浏览。
- 缩略图：用于卡片、列表和聚合预览。

具体采用“引用原文件”还是“复制进资料库”，实施前必须结合赛博书房现有文件管理策略确定，但两种模式都要记录文件指纹和来源路径。

### 13.2 原图失效

原文件移动或删除后：

- 地点记录继续存在。
- 已生成缩略图和预览图继续存在。
- 明确显示“原图不可用”。
- 提供重新关联入口。
- 导出原图时提示失败原因。

## 14. 自动旅程生成

### 14.1 生成原则

系统根据拍摄时间间隔、地理距离和行政区域提出旅程归组建议。例如连续数日拍摄于京都及附近地区的照片，可建议归为“2025 年 4 月·京都”。

### 14.2 用户确认

自动结果必须标记为“待确认”。用户可以：

- 修改名称。
- 修改起止日期。
- 拆分旅程。
- 合并旅程。
- 移动照片。
- 将照片移出旅程。
- 不创建旅程。

### 14.3 不确定情况

时间跨度过长、地点跨度异常或元数据冲突时，不自动归组，只显示建议理由和需要确认的照片。

## 15. 旅程路线与播放

### 15.1 显示条件

路线平时隐藏。只有用户主动打开某次旅程时，才在地球上连接地点。

### 15.2 路线含义

路线只表示照片地点按时间形成的记忆顺序，不代表真实道路、航线、交通方式或精确移动轨迹。

### 15.3 播放流程

1. 地球调整到能容纳全部旅程地点的视角。
2. 路线按日期逐段点亮。
3. 镜头依次靠近地点。
4. 对应照片卡浮现。
5. 用户可暂停、继续或拖动时间轴。
6. 退出后路线隐藏，恢复普通浏览。

### 15.4 缺少地点

旅程中地点不足时，仅按时间播放照片，不绘制虚假路线。

## 16. 世界风景目录

### 16.1 内容策略

第一版使用随应用发布的有限精选风景包。每个地点只保留一至三张代表照片，不提供无限滚动和实时推荐。

### 16.2 必填字段

- 唯一 ID。
- 中文地点名。
- 原文地点名。
- 国家或地区。
- 城市或行政区。
- 经纬度。
- 简短介绍。
- 图片本地路径或受控资源地址。
- 摄影者或机构。
- 原始来源页面。
- 授权类型。
- 授权文本或说明。
- 收录日期。
- 最近核验日期。
- 审核状态。

### 16.3 人工冻结

世界风景的正式展示数据必须来自人工审核后的冻结目录。自动采集或候选照片只能进入审核表，不能直接出现在用户界面。

### 16.4 内容更新

后续版本可以发布风景包更新，但必须：

- 保留版本号。
- 记录新增、替换和移除项目。
- 不覆盖用户的“想去”状态。
- 不覆盖用户个人地点和照片。

## 17. “想去”与“已去过”

### 17.1 想去记录

用户可以对公共地点或搜索到的普通地点标记“想去”。记录包含：

- 地点。
- 标记时间。
- 一句可选原因。
- 可选标签。

公共风景照片不复制到个人照片库。

### 17.2 转为已去过

以后导入该地点附近的个人照片时，系统提示是否转为“已去过／我的足迹”。用户确认后：

- 保留原想去时间。
- 增加首次个人照片日期。
- 建立个人地点记录。
- 关联旅程。
- 移除当前“想去”状态。

用户可以拒绝或稍后处理，系统不得自动改变状态。

## 18. 平面地图整理模式

平面地图不是主浏览界面，只用于精确管理。

### 18.1 主要任务

- 为无地点照片选点。
- 修改错误地点。
- 批量确认同一地点。
- 调整地点名称。
- 拆分被错误合并的地点。
- 查看未确认照片。
- 调整旅程归组。

### 18.2 布局

- 左侧：待确认照片与筛选。
- 中间：平面地图。
- 右侧：所选照片、地点字段和旅程信息。

### 18.3 批量操作

批量操作必须先显示影响照片数量和目标地点，确认后再写入。失败照片单独记录，不回滚已经成功的其他照片，但提供完整结果报告。

## 19. 与个人知识库的关系

### 19.1 默认边界

地点、照片、简短说明和旅程首先属于地球仪记忆库，不自动进入个人知识库首页。

### 19.2 写成记忆笔记

用户可从地点、照片或旅程选择“写成记忆笔记”，在独立编辑界面写旅行感想、地点观察或综合回忆。用户保存后才形成个人知识条目。

### 19.3 引用链

```text
个人知识笔记
  → 旅程
      → 地点
          → 照片
              → 原文件
```

知识笔记需要保留回跳入口。照片或原文件失效时，笔记正文不被删除，并显示引用状态。

### 19.4 Markdown 导出

旅行记忆笔记导出时可包含：

- 标题与正文。
- 地点。
- 日期。
- 旅程名称。
- 标签。
- 照片文件名或本地引用。
- 照片说明。
- 关联地点清单。

## 21. 系统组件边界

### 21.1 GlobeRenderer

负责 3D 地球、光点、聚合、路线、镜头运动和选择状态，不直接处理文件导入。

### 21.2 PhotoImportService

负责文件校验、元数据读取、重复检测、缩略图生成和导入报告。

### 21.3 LocationService

负责本地地点库、在线地点搜索、经纬度解析和地图选点。在线服务必须通过可替换适配层接入。

### 21.4 JourneySuggestionService

负责生成旅程候选和解释归组依据，不直接确认正式旅程。

### 21.5 ScenicCatalogService

负责读取冻结的风景目录和版本更新，不直接修改个人数据。

### 21.6 MemoryRepository

负责地点、照片、旅程、想去状态、回收站和关系数据。

### 21.7 KnowledgeBridge

负责将用户主动保存的旅行笔记及引用关系交给个人知识库。

## 22. 离线与联网策略

### 22.1 离线可用

- 3D 地球。
- 已导入个人照片的缩略图与预览图。
- 已有地点和旅程。
- 世界风景已安装内容。
- 国家、地区和主要城市搜索。
- 旅程路线播放。
- 想去地点查看。
- 地图整理中的基础选点。

### 22.2 需要联网

- 精确街道、地标和小地点搜索。
- 补充地图底图。
- 风景包更新。
- 打开公共照片来源页面。

### 22.3 降级

网络不可用时，所有联网入口显示明确状态并允许重试，但不阻止个人地球浏览和本地整理。

## 23. 隐私与安全

- 经纬度默认只保存在本地。
- 不上传个人照片用于公共风景匹配。
- 不根据照片位置持续追踪用户。
- 不将个人位置写入普通日志。
- 诊断日志中的文件路径和坐标需脱敏。
- 导出或分享包含精确位置的数据前，必须明确提示。
- 备份是否包含原图、预览图和精确位置应可配置。
- 删除私密照片后，清理相关缩略图、预览图和索引。

## 24. 删除、回收站与恢复

### 24.1 删除照片

删除照片前显示其地点、旅程和知识引用。普通删除进入回收站，不自动删除知识笔记。

### 24.2 删除旅程

删除旅程只解除照片归组，不删除照片和地点。

### 24.3 删除地点

地点存在照片或知识引用时，禁止无提示永久删除。用户需要先移动或处理关联内容。

### 24.4 回收站

回收站保留照片记录、地点关系、旅程关系和引用关系。恢复后应恢复原有关联。

### 24.5 永久删除

永久删除后清理主数据、派生图片、搜索索引和缓存，但保留不含隐私内容的删除审计信息。

## 25. 异常处理

| 情况 | 处理方式 |
| --- | --- |
| 照片没有日期或位置 | 进入待确认区，不显示在地球上 |
| 多个地点同名 | 显示国家、地区和坐标候选，由用户确认 |
| 单张处理失败 | 跳过该张，记录原因，继续整批导入 |
| 重复照片 | 显示原记录，允许跳过、重新关联或独立导入 |
| 原文件被移动 | 保留预览与记录，支持重新关联 |
| 地点服务离线 | 使用本地城市库或地图选点 |
| 公共来源失效 | 保留原授权记录，进入维护清单 |
| 风景包损坏 | 回退到上一可用版本，不影响个人数据 |
| 3D 性能不足 | 降低纹理、光效和标记密度 |
| 旅程跨度异常 | 不自动生成，只显示候选与原因 |
| 本地存储不足 | 暂停导入，保留已完成记录并提示释放空间 |

## 26. 性能要求

- 地球光点采用分层聚合与视野裁剪。
- 地球主界面不直接加载所有原图。
- 列表和照片序列使用延迟加载。
- 缩略图生成在后台执行，不阻塞主界面。
- 大批量导入可暂停、继续并显示进度。
- 3D 渲染根据设备性能提供高、中、低档位。
- 镜头运动和路线播放保持稳定，不因后台图片处理明显卡顿。

具体帧率和内存指标需要在取得可编辑源码和目标设备清单后确定。

## 27. 验收标准

### 27.1 空间入口

- [ ] 点击书房实体地球仪可进入全屏地球。
- [ ] 进入与退出动画连续，无明显跳帧或模型瞬移。
- [ ] 减少动态效果模式可用。
- [ ] 返回书房后恢复原镜头和交互状态。

### 27.2 图层与浏览

- [ ] 两个图层可独立开关和叠加。
- [ ] 同一地点优先显示个人内容。
- [ ] 远距离聚合、近距离拆分正确。
- [ ] 点击地点可靠近并展开照片卡。
- [ ] 搜索结果按类型分组。

### 27.3 导入

- [ ] 支持单张、多张和文件夹导入。
- [ ] 可读取可用的拍摄日期和经纬度。
- [ ] 无位置照片进入待确认区。
- [ ] 不随机生成照片位置。
- [ ] 单张失败不终止整批导入。

### 27.4 旅程

- [ ] 可改名、拆分、合并和移动照片。

### 27.5 世界风景

- [ ] 可标记和取消想去。
- [ ] 想去只保存地点和用户文字，不复制公共照片。
- [ ] 导入附近个人照片时提示转为已去过。
- [ ] 未经确认不自动改变状态。

### 27.7 知识库

- [ ] 普通照片说明不自动进入知识库。
- [ ] 用户可主动写成旅行记忆笔记。
- [ ] 笔记可回跳旅程、地点和照片。
- [ ] 删除原照片不会删除笔记正文。

### 27.8 离线、隐私与恢复

- [ ] 断网后可浏览个人照片、旅程和已安装风景。
- [ ] 核心地点搜索离线可用。
- [ ] 坐标和路径不写入普通日志。
- [ ] 回收站可恢复关系。
- [ ] 永久删除可清理派生图片和索引。

### 27.9 视觉与可用性

- [ ] 地球是主视觉，控件不喧宾夺主。
- [ ] 照片卡、文字和地图在常用窗口尺寸下不重叠。
- [ ] 图片不拉伸、不溢出、不遮挡主要交互。
- [ ] 键盘操作和 `Esc` 返回逻辑一致。
- [ ] 完成进入、全球视角、地点详情、旅程播放、导入、待确认、地图整理、离线和异常状态的截图级检查。

## 29. 实施前置条件

开始正式开发前需要：

1. 赛博书房可编辑源码，而不是仅有打包后的 `.app`。
2. 当前 3D 场景、地球仪入口和镜头控制的源文件。
3. 应用现有本地数据库与文件存储规范。
4. 个人知识库最终数据协议。
5. 一组脱敏测试照片，覆盖有／无日期、有／无坐标、重复文件和原图移动。
6. 目标设备与最低性能要求。
7. 第一版公共风景候选表和授权审核结果。
8. 可替换的在线地点搜索服务方案，以及离线地点数据范围。

当前提供的项目中只有打包后的应用成品。正式开发不应直接长期修改压缩后的前端产物，而应在取得可编辑源码后实施。

## 30. 用户已确认的关键决策

- 整体采用“沉浸式记忆地球”方案。
- 使用“我的足迹”和“世界风景”两个独立图层。
- 世界风景第一版采用随应用发布的人工精选图库。
- 个人照片优先读取拍摄位置和日期。
- 无地点照片通过搜索或平面地图选点确认。
- 系统自动提出旅程建议，用户可改名、拆分和合并。
- 3D 地球是主要浏览界面，平面地图负责精确整理。
- 地点记忆采用轻量记录，不扩展成复杂旅行日志。
- 旅程路线平时隐藏，只在打开旅程时播放。
- 公共地点可标记“想去”，导入个人照片后可转为已去过。
- 从书房实体地球仪自然过渡到全屏地球。
- 核心功能离线可用，精确地点搜索和内容更新按需联网。
- 照片和简短说明不自动进入知识库，正式旅行笔记由用户主动保存。
