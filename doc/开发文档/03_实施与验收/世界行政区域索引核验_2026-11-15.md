# 世界行政区域索引核验与修正

日期：2026-11-15。

## 发现与处理

旧海外库的 31,879 条记录确实混用了普通居民点、城市片区、不同层级的行政驻地，还有历史或废弃地点。其中普通居民点有 17,633 条，城市片区有 2,371 条。不能把这些记录共同认定为同级城市。

现在默认索引按 GeoNames ADM2（二级行政区）目录确定身份、名称、代码和上级，居民点仅提供定位参考。二级行政区在各国可能对应县、省、自治体等，不统一称为城市。本轮是行政分类与代码一致性检查，不是逐国政府最新版名录认证；GeoNames 仍可能存在源数据错误。

本轮不改变 CN/HK/MO/TW 数据。大陆此前的 337 条行政定位记录和浙江 11 市回归通过；港澳台不纳入本轮核验结论。

## 当前覆盖与行为

- 海外默认索引为 12,512 个行政单位，覆盖 159 个国家／地区。后台目录共保留 47,371 个 ADM2 单位；缺少可用参考点的单位不生成虚构坐标。
- 默认全库共 13,063 条。旧海外地点保存在 legacy_world_places，不进入默认搜索。
- 原地点与行政区的关联表 world_reference_crosswalk 表示“位于该区”，不表示同一对象。城市、镇与县不能因为使用同一个定位点就视为同一级。
- 11,348 条记录通过明确一级行政代码关联现有地图区域；其余 1,164 条保留来源上级名称，从国家视图定位，不按落点强行匹配不同的行政层级。
- 坐标优先选取与行政单位名称一致的地点，其次考虑行政驻地等条件。所有点保持原 GeoNames WGS84 坐标；不把居民点人口当作行政区人口。参考点不保证为几何中心或政府驻地。
- 界面显示“二级行政区”、来源上级和参考地点；规范名称保留来源英文或本地语言，不从不确定中文别名推断行政名称。只有查询选中后才显示点。个人照片未改动。

## 例子与边界

| 查询 | 返回行政单位 | 说明 |
| --- | --- | --- |
| 巴黎 / Paris | Paris（FR.11.75） | 上级 Île-de-France |
| 京都 / Kyoto | Kyōto Shi（JP.22.1857906） | 使用 Kyoto 参考点，避免源数据中的邻近 Mukō 驻地标记导致误选 |
| 伦敦 / London | Greater London（GB.ENG.GLA） | 上级 England；与现有地图层级不同时从国家定位 |
| 纽约 / New York | New York County（US.NY.061） | 县级行政单位，不等同于整个纽约市 |
| 新加坡 | 国家／现有地区地图 | 该目录没有 ADM2，不虚构城市层级 |

部分原有地点不再能作为独立城市搜索。这是默认索引口径的变化，不表示这些城市不存在。后续如需完整法定城市列表，应按国家补充政府或当地行政名录，而不是恢复混合人口点。

## 验证和维护

全部默认海外记录逐条验证了行政名称、代码、父代码、参考坐标、唯一性和类型；数据库完整性、全文检索无孤儿、前端导出一致性通过。京都参考点和英国层级回退有专项校验。浏览器验证巴黎、京都、伦敦、纽约及嘉兴搜索通过，无脚本异常。生产构建通过；未重新生成安装包。

重建顺序：normalize-china-cities.py、normalize-world-regions.py、export-geography-runtime.py。完整 build-geography.py 已包含两步校正。验证脚本为 verify-world-regions.py、verify-china-cities.py 和 verify-geography.py。

源快照位于 assets/geography/sources/world，详细审计位于 assets/geography/world-administrative-audit.json。运行应用不加载原始目录与历史审计表。

来源：[GeoNames 分类](https://www.geonames.org/export/codes.html)、[目录与字段说明](https://download.geonames.org/export/dump/readme.txt)、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。代码采用 GeoNames 编码口径，不承诺每条都是各国政府公布的官方代码。
