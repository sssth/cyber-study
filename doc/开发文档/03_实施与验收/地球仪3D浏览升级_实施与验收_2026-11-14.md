# 地球仪 3D 浏览升级

## 本轮范围

- 默认进入 3D 浏览，可切换照片整理；沿用原有照片库，不修改存储协议，不自动迁移或改变照片地点。
- 使用现有 React Three Fiber、Three.js 和 OrbitControls，真实球体与经纬度投影。
- Natural Earth 110m 陆地轮廓离线打包；只绘制陆地与经纬网，不含国界。来源及授权见 src/features/globe/ATTRIBUTION.md。
- 已确认、未删除、有效坐标的照片生成暖色光点。同一坐标合并为一个地点，180/-180 经度等价；邻近但不同的坐标不擅自合并。
- 拖动旋转、滚轮及按钮缩放、全球视角、自动旋转、等价方向按钮。用户开始操作立即停止自动旋转；切到后台停止自动旋转。
- 点击光点或地点列表，镜头沿球面方向过渡到目标（不穿过地心），展开纸色照片卡；左右切换、放大照片、Esc 返回和整理这张照片。
- 地点搜索、清空、每批显示 40 地点、空库与无结果状态。照片放大只遍历所选地点的照片。
- 系统减少动态与手动减少动态：关闭自动旋转、镜头即时定位、取消照片卡入场动画。
- WebGL 创建失败或上下文丢失提供降级说明与重试，地点列表和照片卡仍可使用。
- 静态画面按需渲染、像素比封顶 1.5、光点实例化；切换整理会卸载 3D 画布。3D 模块独立延迟加载。

## 验证

- 11 项地理投影和原照片库数据测试通过，包括坐标零点、南北极、经度方向、半径、国际日期变更线、过滤回收站/待确认/非法坐标、同坐标归组、输入不变性，以及前阶段的备份恢复与 EXIF 测试。
- 浏览器使用虚构照片验证真实 WebGL 地球、地点选择、照片切换与全屏、搜索清空、Esc、拖动中断自动旋转、减少动态、整理模式、760px 窄窗口、空库；球面光点直接点击、模拟 WebGL 上下文丢失及重试通过。
- 截图：work/globe-check/3D全球视角.png、3D地点照片.png、3D窄窗口.png。
- 地球仪范围静态 UI 审查通过：work/globe-check/globe-ui-audit.json。全项目审查仍有历史表单/滚动条等差异，保留在 premium-audit.json，不代表全站 UI 已统一。
- 最终 Vite 生产构建通过；仍有原项目的大包体积提示。
