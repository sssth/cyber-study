# 赛博书房项目修改手册

这份手册供第一次打开仓库的维护者使用。路径均相对于项目根目录。先判断需求改变的是哪一层，再按下面的接入方法修改。贯穿各层的约定是：**功能区拥有原始内容，页面声明当前结果，共用命令消费这份结果。**

## 一、按需求找文件

| 要改什么 | 从哪里开始 | 这里负责什么 |
| --- | --- | --- |
| 房间模型、摆位、灯光、机位、热点 | `场景包/<包名>/scene.json`、根目录 `scene.config.json` | 前者描述一个房间，后者选择启动使用的包。加载、校验和渲染在 `src/scenes/`，物件到已有功能的映射在 `featureBindings.js`。 |
| 一个功能区或它的一个页面 | `src/features/<功能目录>/` | `definition.js` 定义功能和实体，`view.jsx` 声明面板和编辑器，同目录放该区的界面、字段转换、业务逻辑与专用样式。普通内容功能的登记表是 `src/features/definitions.js`。 |
| 书房外壳、导航与返回 | `src/App.jsx`、`src/ui/useStudyNavigation.js` | 前者组装场景、面板与全局命令，后者处理实体定位、跨区打开和返回。页面内可恢复的页签、选择和滚动参照 `src/ui/useNavigationState.js`。 |
| 个人知识库、关系、全选和批量操作 | `src/entities/` | `registry.js` 汇总类型，`catalog.js` 从各区读取目录，`EntityCatalog.jsx` 展示，`edges.js` 解析关系；选择与批量写入也在本层。 |
| 搜索框、条件、命中数 | `src/search/` | `UnifiedSearch.jsx` 管输入与筛选控件，`searchStore.js` 管各范围的条件，`searchCore.js` 管通用匹配。专属筛选由功能页提供。 |
| 当前结果与结果应用 | `src/results/`、`src/resultApplications/` | 前者登记当前页面提供哪些实体，后者执行快照、地图投影或关系图展示。 |
| 共用外观与操作 | `src/features/ui.jsx`、`src/ui/`、`src/styles/` | 页面容器和表单骨架在 `ui.jsx`，命令、编辑表面、手势和焦点在 `src/ui/`。共用布局沿用现有样式；模块特例限定在本模块选择器内。可见文案沿用 `src/i18n/`，在 `electron/i18n/zh-CN.json` 和 `electron/i18n/en.json` 配对维护。 |
| 内容字段、存储和桌面文件 | `shared/`、`src/data/`、各功能目录、`electron/` | `shared/contentSchema.js` 定义通用字段默认值，`shared/contentAssets.js` 管内容附件。普通本地集合沿用 `spaceStorage.js`；书籍、地球仪、音乐缓存和快照各有专用存储。系统文件操作经 `electron/preload.cjs` 暴露的接口进入桌面服务。 |
| 资源、工具与验证 | `assets/`、`scripts/`、`tests/`、`doc/` | 内置样例和离线地理资料在 `assets/`。构建与验收脚本在 `scripts/`，局部规则测试紧邻源码，跨模块测试在 `tests/`。需求与验收记录放 `doc/开发文档/`。场景包预览工具、资产关系模拟器是 `doc/` 下的独立工具。 |

开发时编辑源码、配置或源资源。构建网页在 `dist/`，应用安装包在 `release/`，导出的场景在 `场景发布包/`。`.user-data/`、`快照保存/`、`备份/` 和个人 `ai-settings.json` 属于运行数据或个人配置，不能作为新功能源码、示例或测试输入提交。涉及历史数据格式时先查该模块实际的读写入口。[功能模块数据存储清单](开发文档/功能模块数据存储清单.md)

普通编辑表单沿用 .stack-form 的输入框样式，实体标签复用 EntityTagsField。滚动列表的焦点线画在条目内侧，避免首尾被截断。

AI 对话使用本地配置的 `current.provider` 和 `current.model`，按厂商读取 `providers` 中的密钥。新增模型只需修改配置。发布时附带无密钥的 `ai-settings.example.json`，其中的模型参考仅作填写说明。

## 二、沿架构图接入一个功能

图中的主线是 **场景入口 → 功能区 → 实体类型 → 个人知识库汇总 → 搜索与筛选后的实体 → 结果应用**。以电影为例，房间物件绑定功能 ID `movie`，打开 `src/features/movies/`，从本地集合 `movies` 读出影片，知识库以 `movie:<id>` 标识它。同一部影片从书房、目录或关联面板打开，都应定位到同一条记录。[架构图](赛博书房架构图.svg) · [功能区设计初稿](功能区设计初稿.md)

**已有功能加一个视图**，例如在电影收藏内增加一种浏览方式：把页面放回 `movies/`，沿用影片 ID、读写方法和编辑器。新页如果有独立的筛选或返回状态，给它稳定且独立的范围 ID。单纯换展示方式无须建立第二套实体或存储。

**增加独立的内容功能区**，按以下顺序接入：

1. 在 `src/features/<功能目录>/definition.js` 定义唯一的功能 `id`、`label`、`description` 和 `entities`。每种实体提供类型名、标签和 `read(context)`。读取真实存储，沿用记录 ID。按需声明 `search` 关键词字段、`parent` 或 `children` 结构关系、`snapshot` 导出字段。可从目录发起新建的类型才声明 `create`。
2. 在 `src/features/definitions.js` 加入定义。普通功能的菜单项由登记表派生。视图由 `src/features/views.js` 自动发现同目录的 `view.jsx`，用相同的功能 ID 导出 `panel`。目录编辑共用一个表单时导出 `edit`，各实体表单不同时导出 `editors[type]`。编辑组件接收 `editItem`，保存回原记录。参照 [电影功能声明](../src/features/movies/definition.js) 和 [视图声明](../src/features/movies/view.jsx)。
3. 默认打开目标使用功能 ID 作为检索范围、按 `id` 定位。若内容在子页，使用实体定义的 `target` 指明范围或恢复视图。便签和待办共用一个功能、打开不同页签，是已有范例。检查从全局搜索打开、从关联跳转、从知识库新建或编辑三个入口。[便签定义](../src/features/memo/definition.js)
4. 在页面接入下一节的共用能力。登记类型能让目录读取它；新建命令、表单保存、批量写入仍需连接实际业务方法。新增存储类型还要检查旧记录默认值、回收与恢复、批量字段及写入映射。新增结构关系可参照书籍—摘录—批注，用户手动建立的关联继续交给关系面板。[可运行的实体扩展示例](../src/entities/extension.test.js)

## 三、内容页面默认接哪些能力

以可浏览、可编辑的实体集合为默认页面。工具栏和快捷键由应用外壳挂载一次。下表中“页面接入”是新增页面要做的工作。只读详情、设置、局部选取器按实际对象提供支持的动作，避免后台列表误接前台命令。

| 能力 | 默认行为 | 页面接入与允许的差异 |
| --- | --- | --- |
| 页面与返回 | 先展示内容；从编辑、详情或关联返回时恢复来源。 | 普通面板用 `FeaturePanel`，显式给稳定的 `scopeId`。复杂返回交给 `onBack`、`useEscapeBack` 和现有导航；阅读进度、播放位置、草稿各归业务模块。 |
| 搜索与筛选 | 统一搜索条对当前集合即时生效，收起时暂停过滤并记住条件。嵌套面板取得当前范围。 | `useSearchScope({ id, label, filters, priority, enabled })` 注册范围。按返回的状态过滤，用 `useSearchCount` 上报真实计数。原生模态弹窗内的范围用 `searchHost` 返回弹窗或其中的容器；统一搜索只从当前可交互的模态弹窗内选择范围。普通侧栏与所属页面共用稳定的搜索容器；返回时用 `cyber-open-search` 恢复条件，传 `focus: false` 保留当前输入焦点。隐藏但仍挂载的视图应停用范围和结果源。城市自动补全等表单输入保留在表单内。 |
| 当前结果 | `matches` 表示当前范围完整命中的实体，包含尚未分页展示的命中。空集合就传空数组。 | 用 `useResultSource` 提供同一范围的 `scopeId`、`priority` 和 `matches`。原始记录用 `resultEntities(type, records)` 转成实体。异步读取期间标记 `loading`，没有实体输入的前台内容按语义标记 `plain` 或 `blocked`。 |
| 全选与批量编辑 | 普通集合沿用实体全选，至少两条有效实体才进入组选择；再次全选取消，范围或成员失效时清除。批量编辑只显示所选类型共有的可写字段。 | 用 `ContentActions` 或已有的 `data-entity-key` 标识条目。选择由 `entitySelection.js` 维护；新增可批改类型时，对照 `bulkFields.js` 和 `bulkWrite.js` 同时接好字段与写入。局部选取器可通过结果源的 `selectVisible`、`editSelected` 接管动作，保留本地选择上限。 |
| 新建与编辑 | 工具栏和已配置快捷键触发同一命令，普通条目双击进入其编辑动作。新建与编辑沿用相同侧栏骨架。 | `ActionWorkspace` 显式使用 `kind="create"` 或 `kind="edit"`，表单内用 `WorkspaceFields` 与 `WorkspaceActions`。条目用 `ContentCommand` 注册要编辑的对象。工作区默认注册新建命令，纯编辑工作区可设 `command={false}`，避免重复注册。字段校验、草稿、保存失败和删除确认由功能区负责。 双侧有工具栏的集合页在浏览时预留两侧空间，打开侧栏时只移动主体。验收时带上右侧工具栏，点击「编辑」并选择条目，比较打开前后卡片尺寸及关闭后的居中位置。 |
| 关联 | 右键定位内容，打开共用关系面板。结构上的所属、包含和用户手动关联分别维护。 | `ContentActions` 注册 `type`、`id`、`title` 和所属表面；新卡片布局必要时指定 `surface`。关系规则在 `src/entities/contentRelations.js`，面板在 `ContentRelationshipPanel.jsx`。 |
| 快照、地图及其他应用 | 默认消费当前结果。快照冻结并去重记录，生成 Markdown 后由桌面服务存入“快照保存”；地图解析实体关联的记忆点。 | 功能页声明输入，新应用负责处理。选用 `applications[应用ID]` 可以只改变一个应用的实体集合。知识库内嵌关系图直接接收目录的命中集合。 |

**最小接法可看电影页。** 以下是连接顺序，`visibleMovies` 指已经应用关键词和筛选、尚未分页的影片数组。列表渲染与两个公共入口都使用这份结果。[电影页面](../src/features/movies/MovieCollection.jsx)

```jsx
useSearchCount('movie', visibleMovies.length);
useResultSource({
  scopeId: 'movie',
  priority: 10,
  matches: resultEntities('movie', visibleMovies),
});
```

**局部覆盖可看日记阅读页。** 假设筛出三篇日记、当前在第二篇。页面把三篇都放入 `matches`，把第二篇单独放入 `applications.snapshot`，并把三篇显式放入 `applications.selectAll`。这样地图接收三篇，全选也选三篇，快照只保存眼前这一篇。这里必须核对全选：当前实现从快照结果源取输入，优先采用该源的 `applications.selectAll`，省略时会沿用快照输入。其他页面只需要普通集合行为时，提供 `matches` 即可。[日记实现](../src/features/diary/DiaryPanel.jsx) · [全选取数规则](../src/entities/entitySelection.js)

## 四、三类常见修改

### 增加搜索字段或筛选条件

- **让关键词搜到某个字段。** 在实体定义的 `search` 数组加入已有字段名。标题和标签已由 `searchValues` 统一处理。若页面自有全文或段落搜索，再核对它使用的匹配函数。
- **给页面增加筛选。** 固定少量枚举或日期、数值范围适合做筛选。自由填写的标签纳入实体关键词。电影的筛选声明与范围匹配见 `src/features/movies/movieSearch.js`。书库和展示书架复用 `useLibrarySearch`。数值输入通过 `type: "number"` 声明上下限和步长，并由页面解释其业务字段。
- **多个集合共用同一筛选语义。** 在 `searchCore.js` 的匹配逻辑中处理字段，在支持它的范围注册选项。全局搜索与知识库各有自己的范围配置，分别决定是否展示。用旧记录、空条件、组合条件验证；仅声明控件无法完成过滤。

### 增加一种结果应用

例如将当前结果按时间展示：在 `src/resultApplications/` 写处理和展示逻辑。若从全局命令启动，在触发时调用 `currentResultInput('timeline')`，读取 `entities`；`matches` 仍可用于了解原集合。检查加载、不可用、空结果，按业务需要去重。命令型应用参照 `ResultApplications.jsx` 登记。需要新增工具栏按钮或可配置快捷键时，再接 `src/ui/commands.js`、`CommandToolbar.jsx` 和 `src/data/shortcuts.js`。若仅在知识库内展示，可参照 `EntityGraph.jsx` 由父页面传结果。选两种已有内容页测试同一应用，其中一种带筛选，确认都读取前台页面。

### 增加场景入口

新房间放在 `场景包/<包名>/`，清单的模型 `feature` 填已登记的功能 ID，如影片填 `movie`。显式填 `null` 表示装饰物，未填写时加载器会尝试模型 ID。只有新增房间动作时才扩展 `src/scenes/featureBindings.js`。需要切换启动场景时修改 `scene.config.json` 的 `sceneFolder`。详细制作步骤统一维护在[场景制作格式](场景包预览工具/场景制作格式.md)。验收时分别从场景热点和互动菜单进入同一功能。

## 五、改完怎么判断接对了

| 改动 | 用什么情形验收 |
| --- | --- |
| 新内容页或新类型 | 从功能区新建一条记录，在知识库搜索并编辑它，再回原页检查；重开后仍是同一 ID 和同一份内容。支持删除时验证回收与恢复。 |
| 搜索、全选或快照 | 准备三条记录，令筛选命中两条。列表、计数、全选和快照应各自得到约定范围。再试零条、一条、多页，以及打开子面板后触发命令。 |
| 编辑或导航 | 从工具栏与已绑定快捷键进入同一新建流程，双击指定条目编辑。分别验证保存、取消、保存失败、返回后的焦点和滚动位置。批量写入部分成功后，重试只作用于剩余记录。 |
| 公共机制 | 同时检查一个普通调用方（如电影）和一个有覆盖的调用方（如日记）。只给单页增加特例时，其他页面应继续走原默认路径。 |

规则与数据运行 `pnpm test`，编译入口运行 `pnpm build`，涉及实际手势、快捷键、布局或跨页返回时运行 `pnpm test:ui` 并实测新路径。界面测试使用独立 Electron 会话，需要可用的图形环境和空闲的 5173 端口。交付时写明已验证的入口和仍未验证的情况。

公共入口、默认行为或覆盖方式改变时，更新本手册对应行。视觉规格更新到 [DESIGN.md](../DESIGN.md)，操作规则更新到 [UX-CONTRACT.md](../UX-CONTRACT.md)。两份文档都保留历史记录，阅读时按功能查找最近一次修订，并核对当前组件及测试；需求初稿中的设想应与已实现行为分别说明。

## 使用建议

项目根目录的[使用建议文稿](../使用建议.md)是页面清单、轮换说明和中英文建议的维护入口。已有页面改文案只改此文件。新页面用 `FeaturePanel` 的 `tipPage`（默认取 `scopeId`）声明文稿里的固定标识；独立阅读页和模态页面在自己的根元素声明 `data-tip-page`。同种页面的不同记录共用一个标识。先在电影页翻一条，切到日记再回电影，确认两个页面各记各的进度；再测互动菜单开关、编辑侧栏和窄窗口。

使用建议与六键栏的固定位置由 immersive.css 共用布局变量控制。验收时对比两栏开合和切换长短建议前后的顶边坐标。

全屏阅读与沉浸抄写的右侧六键栏和使用建议默认完全隐藏。指针移到窗口最右侧可临时显示，移回正文后收起。全局检索沿用书房首页建议；地图投影、内容关联、宠物和植物不提供建议。

互动菜单中的「功能按键」默认开启，控制右侧六键栏（含折叠按钮）的显示。与「使用建议」分别保存，重开书房后沿用各自的设置。

可检索的实体复选列表通过共用的 CheckboxPicker 接管全选。搜索框聚焦时，全选作用于当前匹配的全部可选项，包含其他页；再次全选只取消这些匹配项。名称、说明等普通输入框保留文字全选。

实体编辑的单图字段复用 `src/features/ImageFileField.jsx`。传入图片名称、文件选择事件和预览组件，业务表单负责草稿及保存。

实体编辑字段依次排列为标签、名称与基本信息、正文、状态与日期、附件、成员关系、只读信息。次要操作单独成组，保存与删除位于底部。字段名占 64px，控件列与字段名间隔 14px，主字段行间距 22px。布尔开关放在右列；成员与来源选择保留组名，单选和多选沿用相同的选项行尺寸。日记本在纸面编辑正文，知识库在侧栏编辑正文。

字段命令由 `src/search/queryFields.js` 将当前范围映射到已有可搜属性，`logicQuery.js` 解析布尔表达式，`QueryInput.jsx` 负责菜单与输入草稿。增加字段时核对源属性、菜单所属范围和实际匹配调用方。用“属性未填写”“其他实体不支持该属性”“NOT 包含不适用字段”分别验收。

字段菜单以存储属性名为唯一标识，按登记类型汇总共享范围。例如书名、歌单名与曲名共用 `title`；显示名称和旧查询别名可以不同。验收时同时覆盖知识库跨类型命中与功能页范围。

字段归属核对见[本机存储与检索清单](全项目检索与筛选清单.md)。当普通搜索兼容的属性与当前编辑器实际写入不同，用实体定义的 `commandFields` 收窄命令候选，保留 `search` 的兼容匹配。

全局搜索和知识库实体视图通过 relatedSearch 启用后缀保留字 `RELATED`。关键词后可直接输入 /，选择命令时自动补分隔空格。运算优先级与斜杠菜单顺序共用 logicQuery.js 中的 precedence。先按 RELATED 左侧紧邻的条件或括号组及当前筛选查出直接命中，再沿关系图谱的直属、包含和手动关联双向扩展一层。结果计数和结果应用使用去重后的同一集合。

调整目录关键词时，同时核对功能页的实际匹配和斜杠菜单顺序。地理层级保留 country、region、city 的连续顺序，电影 genres 和 movie.region 保留关键词入口。检索命令 key 与源属性 sourceKey 可以不同，例如 movie.region 读取影片 region。摘录和批注的目录实体均保存 text。旧笔记首次读取时原子转换为同一位置下的 excerpt.text 和 comment.text，回收站按同一规则转换。具体范围见[检索清单](全项目检索与筛选清单.md)。

### 实体字段和默认搜索范围

在 src/search/queryFields.js 登记文本范围，在 typedFields.js 登记可指定属性、类型、显示含义和取值。设置页和斜杠菜单读取同一份实体字段定义。原关键词字段默认勾选，新扩展的状态、数值、日期和图片默认关闭；仅保存用户修改的勾选项。书籍正文的普通匹配还取决于该页的全文范围。新增条件时核对本页、跨实体目录和旧记录默认值。用 score:FROM 0 TO 6、watchedOn:2021年1月1号、photo:NO 和 readingStatus:reading 验证不同字段类型。

实体范围使用保留字 `TYPE`（例如 `TYPE book`），选择后列出当前范围支持的实体类型。旧写法 `type:book` 仍可读取。书房菜单的“搜索字段”只分公共字段和专属字段，公共在前。公共查询属性为 tags、title、text、photo、createdAt、updatedAt，按实体实际支持情况显示。photo 统一判断图片存在性。仅在同一业务内复用的属性归入专属字段。斜杠菜单公共字段只列一次并提示适用实体，专属字段按实体分别列出；例如歌单和曲目的 provider 分别插入 playlist.provider: 和 music.provider:。

电影影评、旅途描述、记忆点说明、歌单描述、曲目备注统一写入 text；字段设置按实体显示原业务名称。旧描述字段在读取时迁移，回收站、歌单成员和地球仪旧备份沿用相同转换。来源书籍 ID 保留在存储与关系中，用户检索来源书名使用 bookTitle。

右侧筛选由 `src/search/filterExpression.js` 转换成搜索语句。实体条件直接交给当前范围的查询器。阅读上下文等页面选项从同一语句解析。新增筛选要验证点选、手写、改选及清除能得到一致结果，并覆盖已有 OR 或 RELATED 的输入。

「检索表达式转换 AI」从独立 AI 小窗打开，使用系统默认 AI。字段资料和回复验收在 src/search/expressionAssistant.js；协议见[AI 检索表达式转换约定](AI检索表达式转换约定.md)。调整字段时同时验证候选生成范围、追问、应用后的筛选回显和上下文清空。

独立 AI 侧栏入口在 src/ui/AIWindow.jsx，由互动菜单的 AI 开关控制显示。快捷键 openAI 默认为 Shift+Cmd+D 和 Alt+Shift+D，侧栏隐藏时也可打开。快照对话和检索表达式共用桌面默认模型；同页分开保留上下文，切换页面、手动重置或应用表达式时按交互约定清理。

SnapshotCommand 保存快照时通知当前页快照对话。附件使用实际保存的文件名，发送时读取并沿用水晶球 snapshotPrompt 的快照正文格式。

桌面 AI 的检索目标入口为 src/features/CrystalExpression.jsx，目标选择器只登记固定页面，展示书架从当前场景的 displayShelves 声明生成。具体书籍的阅读页与单篇作品的抄写页只在实际打开时提供当前页检索。离线选择的目标和前台小窗共用 searchCapabilities 和 validCandidate。调整带模式的范围时同步检查 src/search/pageModes.js。

唱片机右侧的曲名、歌手名、歌单名选择器直接生成实体类型和字段表达式。选择歌单名只查标题，命中后展示符合平台条件的成员曲目。

地图区域探索和投影使用 TYPE journey 选择旅途，展示命中旅途的未删除成员点并遵循当前地图区域。书籍正文的普通关键词匹配由搜索字段设置控制，显式 content 条件直接匹配正文。

菜单切换子页时使用 DisplayViewMenu 或在切换前调用 closePageTools，收起当前编辑、新建和搜索。常驻功能退出时清理面板的临时打开状态，保留播放等后台任务。
