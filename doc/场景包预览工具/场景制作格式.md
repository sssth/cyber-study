# 场景包制作指南

本指南定义赛博书房场景包格式 v1。你可以用自己的模型从空目录开始制作。准备一个能导出 GLB 2.0 的建模工具和一个纯文本编辑器即可编写场景包。有场景包预览工具时，可以进一步检查实际画面和声音。

## 1. 建目录和导出模型

新建一个文件夹，名称由你决定。交付时保留整个文件夹及内部路径。

```text
<场景包文件夹>/
├── scene.json       必需，场景配置，文件名固定
├── models/          建议用来存放 GLB，至少提供一个被配置引用的模型
├── textures/        可选，存放主题切换用的贴图和光晕图片
└── audio/           可选，存放主题使用的循环音轨
```

- 可以把整个房间导成一个 GLB。要单独调摆位、换主题时隐藏，或绑定点击功能的物件，分别导出为 GLB。同一个 GLB 可被多个物件引用，每个物件各自填写 ID 和摆位。
- 导出时把模型几何、基础材质和模型使用的贴图嵌入 GLB。GLB 中的缓冲区和贴图应随文件交付。主题替换贴图和循环音轨则作为独立文件放在包内。
- 房间要在建模时留好窗洞、处理好玻璃透明度。需要投影的网格可在 GLB 的 `extras` 中设布尔值 `castShadow` 和 `receiveShadow`。带主题时，普通不透明且受光的网格默认投射并接收阴影。模型动画目前不会自动播放。
- 配置中的文件路径从 `scene.json` 所在目录算起。使用正斜杠，大小写与实际文件名一致。路径必须留在包内，避免绝对路径、网址、盘符、空路径段和 `.`、`..`。

## 2. 从空白写 scene.json

1. 在场景包根目录新建 UTF-8 纯文本文件 `scene.json`。整份文件是一个 JSON 对象，从 `{` 开始，以 `}` 结束。
2. 在顶层依次写四个必填字段 `version`、`name`、`models`、`camera`。`version` 填数字 1，`name` 填你自己的场景名称。
3. `models` 是数组，用方括号包住一个或多个物件对象。每个物件先填 `id`、`file`、`width`、`position`。先放房间或地面，再放独立物件。
4. `camera` 是对象，先填 `position` 和 `fov`。相机放在空处，Y 坐标设为合适的眼高，初始视野可从 65 度调起。根据开场画面再调整朝向。
5. 基础摆位完成后，按需加入机位、灯光、声音、雨景、漫游和热点。字段的排列顺序可以自行决定，`models`、`views` 等数组保留元素顺序。

字段名和字符串用英文双引号。冒号分隔字段和值，逗号分隔同一层的字段或数组元素，最后一项后不加逗号。JSON 不支持注释。数字、布尔值 `true` 和 `false`、空值 `null` 直接写。未使用的可选字段通常直接省略。

### 顶层字段

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `version` | 必填，数字 | 固定为 `1` |
| `name` | 必填，字符串 | 场景名称 |
| `models` | 必填，数组 | 至少一个物件，见第 3 节 |
| `camera` | 必填，对象 | 初始相机与视角限制，见第 4 节 |
| `views` | 可选，数组 | 可切换机位，见第 4 节 |
| `roam` | 可选，对象 | 第一人称移动，见第 4 节 |
| `appearance` | 可选，对象 | 每套主题的灯光、画面、显隐和声音，见第 5、7 节 |
| `outdoorRain` | 可选，对象 | 窗外雨区域和雨滴参数，见第 6 节 |
| `hotspots` | 可选，数组 | 画面上的可点击标记，见第 8 节 |
| `systemFeatures` | 可选，数组 | 给制作者看的功能对照清单，见第 8 节 |

全包使用同一套世界坐标。`[X, Y, Z]` 中 X 向右、Y 向上，初始相机在朝向角为零时看向 −Z。建议按 1 个场景单位约等于 1 米制作。位置、宽度和移动范围使用场景单位，旋转与朝向使用弧度，视野使用度。

## 3. 物件 models

每一项是一个对象。

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `id` | 是 | 非空字符串，在本包内唯一，大小写敏感。其他配置通过它引用物件 |
| `file` | 是 | 包内 GLB 的相对路径，扩展名为 `.glb` |
| `width` | 是 | 正数。物件旋转后沿世界 X 轴的目标宽度，其余方向等比缩放 |
| `position` | 是 | 三个数字 `[X, Y, Z]`。X、Z 定位物件包围盒的底面中心，Y 定位底面高度 |
| `rotation` | 否 | 三个数字，分别绕 X、Y、Z 轴旋转，单位弧度，默认 `[0, 0, 0]`。1.57 弧度约为 90° |
| `feature` | 否 | 点击功能 ID。填 `null` 可显式禁用。省略时尝试用物件 ID 匹配系统功能 |
| `qualityFiles` | 否 | 可选的低、中画质 GLB，如 `{"low":"models/quality/low/sofa.glb","medium":"models/quality/medium/sofa.glb"}`。高画质及未提供的档位使用 `file`。副本须保持同一几何尺度、原点、材质名称与朝向，可降低贴图分辨率。所有路径均需位于包内。 |
| `support` | 否 | 承托物的物件 ID，用于把小物件贴到桌面或书架上 |
| `surfaceCeiling` | 否 | 从此世界 Y 高度向下找承托面，默认 10。可把起点设在两层搁板之间以选中较低的一层 |

程序先旋转模型，再用包围盒计算缩放与落位。调完旋转后重新检查 `width`，尤其是宽深不同的物件。定位以包围盒底面为准，建模软件中的原点位置不决定落位。

设了 `support` 时，程序从物件的 X、Z 坐标向下找指定承托物的表面。命中后把底面放到表面上方 0.005 单位。未命中时保留填写的 Y。承托物必须存在，不能引用自身，也不能再依赖另一件承托物。若贴面结果不理想，可以去掉 `support` 并手动设置 Y。

## 4. 相机、机位与漫游

### camera

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `position` | 是 | 相机所在的三维坐标 |
| `fov` | 是 | 垂直视野，30–100°。数值越大，画面取景越广 |
| `yaw` | 否 | 水平朝向，弧度，默认 0 |
| `pitch` | 否 | 上下朝向，弧度，默认 −0.08 |
| `far` | 否 | 最远可见距离，10–2000 个场景单位，默认 150。近裁剪距离固定为 0.1 |
| `limits` | 否 | 固定站位下的环顾和滚轮视野范围，每项写成 `[最小值, 最大值]` |

`limits.yaw` 控制左右环顾，默认 `[-0.85, 0.85]` 弧度。`limits.pitch` 控制上下环顾，默认 `[-0.5, 0.45]` 弧度。`limits.fov` 控制滚轮视野，默认 `[45, 85]` 度，两端都须在 30–100° 内。初始镜头可以在操作范围外，开始拖动或滚轮调整时会受到范围限制。

### views

想让使用者快速切到不同区域时，添加 1–9 个机位。第一项是开场机位，各项按顺序对应数字键 1–9。设置了机位后，机位的站位、落点和视野优先用于取景。`camera` 仍为必填，远裁剪距离等全局设置仍从它读取。

| 每项必填字段 | 含义 |
| --- | --- |
| `id` | 唯一机位 ID，可用英文字母、数字、短横线，首字符为字母或数字 |
| `label` | 机位按钮显示的名称 |
| `position` | 相机站在哪，填写三维世界坐标 |
| `target` | 镜头看向哪，填写三维世界坐标。须与相机位置不同 |
| `fov` | 垂直视野，30–100° |

调整机位时，先用 `position` 找站位，再把 `target` 放在要看的物件或区域上，最后用 `fov` 调整构图范围。

### roam

想在应用视角中走动时，加入 `roam` 并填写下列全部字段。WASD 或方向键水平移动，Q 下降、E 上升，滚轮前后移动。漫游限制在指定长方体内，家具几何不参与碰撞。

| 字段 | 含义 |
| --- | --- |
| `min`、`max` | 可移动区域的两个三维角点，每轴最大值都须大于最小值 |
| `speed` | 移动速度，0.1–20 场景单位每秒 |
| `eyeHeight` | 水平移动时相机逐渐回到的世界 Y 高度，须在边界的 Y 范围内 |
| `transition` | 切换机位的过渡时间，0–10 秒。0 为立即切换 |

启用漫游后，滚轮用于前后移动，左右可以转身，上下俯仰由程序限制。

## 5. 灯光、画面和主题 appearance

省略 `appearance` 时，应用使用内置照明与背景。自定义画面时，在 `appearance` 中写一个 `themes` 对象，以主题 ID 为键，每个值是一套主题参数。主题 ID 使用英文字母、数字、短横线，首字符为字母或数字。

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `defaultTheme` | 是 | 开场主题 ID，须存在于 `themes` |
| `nightTheme` | 否 | 主应用日夜按钮使用的夜间主题 ID，须存在且与默认主题不同 |
| `themes` | 是 | 主题 ID 到主题配置的对应关系，至少包含默认主题 |

预览下拉框可切换每套主题。主应用通过日夜开关切换默认与夜间主题。夜间开启窗外雨时，会优先选取第一套标有 `rain: true` 的主题。其他主题可在预览中查看，主应用当前没有通用的主题下拉框。

### 每套主题的参数

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `label` | 是 | 非空显示名称 |
| `background` | 是 | 画面背景色，`#RRGGBB` 格式 |
| `fog` | 是 | 雾色，`#RRGGBB` 格式 |
| `fogDensity` | 是 | 雾密度 0–1，0 为无雾。轻雾从较小数值调起 |
| `exposure` | 是 | 曝光 0.05–10，数值越大越亮 |
| `lights` | 是 | 灯光数组，最多 100 盏。允许空数组 |
| `dimWithRoomLights` | 否 | 关灯后各灯强度乘以此数，0–1，默认 1 |
| `hidden` | 否 | 此主题隐藏的物件 ID 数组，引用 `models` 中的 ID |
| `environment` | 否 | 给材质提供反射的环境背景和面板 |
| `materials` | 否 | 按材质名称覆盖模型材质 |
| `glows` | 否 | 面向镜头的发光贴片 |
| `rain` | 否 | 布尔值，是否让此主题显示窗外雨。还须配置顶层 `outdoorRain` |
| `mix`、`audioLoop` | 否 | 环境混音和包内循环音轨，见第 7 节 |

### lights 灯光

每盏灯都填写 `type`、`color`、`intensity`、`position`。颜色用六位十六进制，强度范围 0–10000，位置是世界三维坐标。环境光和半球光仍须填写 `position`，但位置不用于控制照明覆盖范围。

| `type` | 用途和附加字段 |
| --- | --- |
| `ambient` | 全局均匀补光 |
| `hemisphere` | 天空与地面两色补光。`color` 为天空色，另须填地面色 `ground` |
| `directional` | 平行光，适合日照。须填三维 `target`，决定照射方向 |
| `point` | 向四周发光，可设 `distance` 和 `decay` |
| `spot` | 锥形光，须填三维 `target`，可设 `distance`、`decay`、`angle`、`penumbra` |

`distance` 是照射距离，0–2000，0 表示没有距离截断。`decay` 是随距离衰减的指数，0–10。`angle` 是聚光锥半角，0.01 至 π/2 弧度。`penumbra` 是聚光边缘柔化程度，0–1。

平行光、点光和聚光灯可加 `shadow` 对象。省略时这盏灯不投射阴影。

| 字段 | 含义 |
| --- | --- |
| `size` | 阴影贴图分辨率，取 256、512、1024、2048 或 4096 |
| `near`、`far` | 阴影相机的近远距离，范围 0.01–2000，远端至少比近端大 0.01 |
| `bias`、`normalBias` | 深度偏移和沿表面法线的偏移，均为 −1 至 1。出现条纹或阴影与物件分离时，从小幅调整开始 |
| `bounds` | 平行光必填，按 `[左, 右, 上, 下]` 填写阴影相机范围。左小于右，下小于上 |

### environment、materials 和 glows

- `environment` 填 `background`（反射环境的背景色）与 `panels`（最多 16 项）。每个面板都填 `color`、`intensity`（0–100）、`size`（宽、高各 0.01–1000）、三维 `position` 和三轴 `rotation`（弧度）。主题自身的 `background` 单独控制镜头看到的背景。
- `materials` 的键必须与 GLB 中的材质名称完全一致。多个物件共用同名材质时会一起命中。希望单独调整时，在建模软件中给材质起不同名称。

| 材质字段 | 含义 |
| --- | --- |
| `color` | 底色，`#RRGGBB` |
| `roughness`、`metalness` | 粗糙度、金属度。制作常规材质时按 0–1 调整 |
| `emissiveIntensity`、`envMapIntensity` | 自发光强度、环境反射强度。自发光颜色由 GLB 材质提供 |
| `clearcoat`、`clearcoatRoughness` | 清漆层强度和粗糙度，通常按 0–1 调整，取决于模型材质是否支持 |
| `toneMapped` | 布尔值，是否对该材质应用色调映射 |
| `additive` | 布尔值，开启时以叠加方式绘制，适合光痕 |
| `texture` | 底色替换贴图对象。填 `file`（包内 PNG、JPG、JPEG 或 WebP 路径）和 `repeat`（横向与纵向重复次数，各 0.01–1000） |

材质表中的数值属性通过格式校验的范围为 0–100。省略的属性保留模型材质原值。

`glows` 填 `file`（包内 PNG、JPG、JPEG 或 WebP）和 `sprites`（最多 100 项）。每项填 `position`（三维位置）、`size`（宽、高各 0.01–100）、`color`（六位十六进制）和 `opacity`（0–1）。所有贴片使用同一张图片，并始终面向镜头。

## 6. 窗外雨 outdoorRain

先把区域放到窗外，再通过机位确认室内看不到穿墙的雨。使用自定义主题时，在需要下雨的主题上设 `rain: true`。省略整个 `appearance` 时，仍可使用窗外雨。

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `min`、`max` | 是 | 雨区的两个三维角点，每轴最大值都须大于最小值 |
| `regions` | 否 | 用多个区域覆盖不同窗户。数组至少一项，每项都有 `min`、`max`。填写后雨滴在这些区域生成，顶层的两组角点仍须填写 |
| `count` | 否 | 雨滴总量，1–10000 的整数，默认 480 |
| `speed` | 否 | 下落速度，0.1–100 场景单位每秒，默认逐滴在约 5–8 之间变化 |
| `length` | 否 | 最短、最长雨滴，按升序填写，两端均为 0.01–10，默认 `[0.09, 0.22]` |
| `color` | 否 | 雨滴颜色，默认 `#a0c5de` |
| `opacity` | 否 | 雨滴透明度，0–1，默认 0.32 |

## 7. 声音

在每套主题里配置声音。用户开启「场景声音」后，应用播放当前主题的混音与循环音轨。

| 字段 | 含义 |
| --- | --- |
| `mix.rain` | 应用合成的雨声，0–1 |
| `mix.hum` | 应用合成的设备低鸣，0–1 |
| `mix.city` | 应用合成的远处城市声，0–1 |
| `audioLoop.file` | 自带循环音轨的包内相对路径，扩展名支持 MP3、OGG、WAV、M4A、FLAC，实际播放取决于浏览器解码 |
| `audioLoop.gain` | 循环音轨音量，0–1。使用 `audioLoop` 时与 `file` 一起填写 |

省略整个 `mix` 会使用内置混音。填写了 `mix` 时，其中省略的轨道按 0 处理。要只播放包内音轨，可将 `mix` 写成空对象 `{}`。合成雨声与可见雨景是独立参数，希望停雨主题安静时也要调整 `mix.rain`。应用总音量会影响最终播放音量。

## 8. 热点与功能绑定

绑定功能有两个入口。物件可填 `models[].feature`，主应用点击该物件时触发。也可添加 `hotspots`，在世界坐标中摆放一个带标签的按钮。可将多个物件绑到同一个功能，每个物件仍使用自己的 ID。物件未填 `feature` 时，程序用物件 ID 尝试匹配。纯装饰可填写 `feature` 为 `null`。

`hotspots` 最多 100 项，每项包含以下字段。

| 字段 | 必填 | 含义 |
| --- | --- | --- |
| `id` | 是 | 唯一热点 ID，规则与机位 ID 相同 |
| `label` | 是 | 显示在画面上的文字 |
| `position` | 是 | 标签锚点的三维世界坐标 |
| `feature` | 是 | 要触发的系统功能 ID |
| `view` | 否 | 只在哪个机位显示，须引用 `views` 中的机位 ID。省略时所有应用机位都可显示 |

| 功能 ID | 主应用中的动作 |
| --- | --- |
| `shelf` | 打开书库 |
| `desk`、`knowledge` | 打开知识库与创作台 |
| `window` | 开关窗外雨，需有 `outdoorRain` |
| `lamp` | 开关灯光 |
| `music` | 打开音乐 |
| `movie` | 打开电影收藏 |
| `diary` | 打开日记 |
| `memo` | 打开便签与待办 |
| `globe` | 打开地点照片 |
| `typewriter` | 打开抄写功能 |
| `cat`、`pet` | 打开猫互动，新包可用 `cat` |
| `plant` | 打开植物功能 |

`systemFeatures` 可用于随包记录功能对照。数组每项填 `id`（功能 ID）、`label`（名称）、`description`（说明）和 `models`（引用本包物件 ID 的数组，可为空）。程序按物件和热点的实际绑定触发功能。这份清单仅供阅读，功能界面由主应用提供。

## 9. 预览、排查和交付

1. **打开。** 如已安装场景包预览工具，启动「打开场景包预览.command」，在桌面版 Chrome 或 Edge 中选择直接包含 `scene.json` 的那层文件夹，并允许读写。
2. **调物件。** 点击画面中的物件或从「查看物件」选择，在右侧结构化编辑中调整已有字段。用自由视角检查间距、遮挡和承托。新增物件、机位、灯光、主题或音轨时，切到「原始 JSON」。
3. **调取景和主题。** 回到应用视角，检查开场和每个机位。逐套切换主题，检查灯光、阴影、材质、雨区与物件显隐。开启场景声音试听，再检查漫游边界和热点位置。预览点击物件用于选中编辑，实际功能在主应用验证。
4. **保存和重读。** 点「校验并保存」写回 `scene.json` 并更新预览。失败时按提示修正。若在外部修改了 JSON 或替换资源，先处理预览中的未保存修改，再点「重新读取场景包」。
5. **交付。** 把 `scene.json` 与所有引用的资源一起交付，可以压缩整个场景包文件夹。接收方解压后，直接选择含有 `scene.json` 的那层目录。主应用使用哪个场景由安装方在项目根目录的 `scene.config.json` 中通过 `sceneFolder` 指定。已打包应用需要重新打包以带入更新后的场景。

| 遇到的问题 | 先检查哪里 |
| --- | --- |
| 找不到配置或资源 | 目录选对了吗，文件名和路径大小写是否一致，资源是否随包 |
| 模型无贴图或加载失败 | GLB 是否为 2.0，几何和模型基础贴图是否已嵌入 |
| 物件尺寸不对、悬空或穿插 | 核对旋转后的 X 宽度、底面坐标和承托起始高度 |
| 修改了相机，开场构图没变 | 若有 `views`，改第一项的站位、落点和视野 |
| 切换灯光或材质没效果 | 检查当前主题、灯光强度、关灯倍率和 GLB 材质名称 |
| 看不到窗外雨 | 检查窗洞和玻璃、雨区坐标、当前主题的 `rain` 与预览开关 |
| 听不到声音 | 检查播放开关、轨道增益、包内路径和浏览器解码 |
| 主应用点击没反应 | 核对系统功能 ID、物件的 `feature` 或热点配置 |

校验通过后再从实际机位检查画面。格式校验能发现字段、路径和 GLB 结构问题，构图、光照和音量仍要靠预览确认。
