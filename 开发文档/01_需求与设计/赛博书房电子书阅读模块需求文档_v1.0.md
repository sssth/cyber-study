## 2 最高优先级产品原则

赛博书房不是稍后再看清单，也不是无限收藏箱，而是用户主动筛选、愿意长期理解并纳入个人知识体系的书影音珍藏库。

能够进入赛博书房的书籍、电影和音乐，必须是用户真正喜欢、明确确认并愿意反复阅读、观看、聆听或回顾的内容。数量可以少，但用户应当对其中内容如数家珍。产品不以扩大收藏数量、追逐热门或制造待办焦虑为目标，而以沉浸、理解、回看、关联和个人知识积累为目标。

电子书模块必须遵循以下原则：

1. 外部书单不能未经确认直接灌入书架。
2. 每一本进入书架的书都应经过用户主动确认。
3. 待读不等于随手收藏，而是用户已经确认将要阅读的书。
4. 已读书是个人知识体系的一部分，即使暂时没有本地正文，也应保留其书目、阅读状态和个人记录。
5. 阅读界面以正文为中心，管理、推荐和 AI 默认隐身。
6. 搜索结果必须能够回到原文和来源，不用无法核对的总结代替证据。

## 3 产品定位

电子书模块定位为赛博书房中的个人精选阅读库，由右侧休闲书架、二维分层书架和纯净阅读器组成。

本模块主要收录小说、文学、历史、艺术、社会科学、绘本、摄影等休闲或通识阅读内容。左侧书架承担学术资料知识库入口；右侧书架承担休闲阅读入口。两侧书架的数据最终汇入统一知识库，实现跨书籍、资料、划线和笔记的全文与语义检索。

本模块不复制微信读书、豆瓣读书等平台的完整功能，不提供热门榜单、社交评论、无限推荐或未经确认的批量收藏。

## 4 目标与非目标

### 4.1 产品目标

- 让用户从三维书房自然进入右侧休闲阅读区。
- 以真实分层书架展示用户确认收录的书。
- 支持本地 EPUB 和文字版 PDF 阅读。
- 支持微信读书书单和豆瓣已读记录的受控导入。
- 提供纯净阅读、目录、书签、划线、笔记、全文搜索和语义搜索。
- 自动记录进度、阅读时长和阅读状态。
- 将休闲阅读中的划线、笔记与书签自动沉淀到统一知识库。
- 保留原始文件、书目来源、阅读位置和笔记回跳关系。

### 4.2 本期非目标

- 不做热门发现、排行榜或算法推荐。
- 不做阅读社交、评论社区或公开书评广场。
- 不自动抓取或下载受版权保护的 PDF、EPUB 或 Markdown 正文。
- 不绕过微信读书、豆瓣或其他平台的登录、付费、DRM 与版权限制。
- 不支持扫描版 PDF 的 OCR；扫描版 PDF 在本期明确提示暂不支持。
- 不做复杂的图书借阅、交易或云端书城。
- 不把未经用户确认的外部书单长期保存在个人书架中。

## 5 当前能力与迁移要求

当前版本已具备以下基础能力：

- 导入 Markdown、TXT 和文字版 PDF。
- 保存导入原件和转换后的 Markdown 正文。
- 保存书籍基本信息。
- 支持书架、阅读进度与基础笔记能力。
- 文字版 PDF 可提取正文；扫描版 PDF 当前无法提取。

新版要求：

- 新增 EPUB 作为主要休闲电子书格式。
- 新版用户界面主推 EPUB 和文字版 PDF。
- 已导入的 Markdown、TXT 与旧版 PDF 不得失效，作为兼容格式继续阅读。
- 旧书籍、进度、笔记和摘录迁移后不得丢失。
- 原有 Markdown 阅读器名称和技术细节不再作为用户界面的主标题。
- 迁移前必须备份旧书库；迁移过程需要记录成功、跳过和失败项。

## 6 三维书房入口与空间职责

### 6.1 右侧休闲阅读架

- 右侧书架固定为休闲阅读入口。
- 用户从主场景进入阅读功能时，镜头优先移动到右侧阅读区。
- 用户点击右侧书架后，打开二维休闲书架界面。
- 右侧书架不承担学术资料、唱片或影碟入口。

### 6.2 左侧学术资料知识库

- 左侧书架代表学术资料知识库。
- 本期不重做整个左侧书架。
- 在远离唱片机和影碟机的书架下层设置独立可点击区域。
- 点击该区域进入学术书库或统一知识库。
- 唱片机、影碟机和学术书架必须拥有互不重叠的交互热区。

### 6.3 空间交互要求

- 鼠标悬停或焦点进入时，应明确提示当前物件名称和作用。
- 不允许用覆盖整个左侧书架的大热区遮挡唱片机或影碟机。
- 关闭二维阅读界面后，返回进入阅读前的三维位置和视角。
- 三维空间只负责入口和氛围；长时间阅读在清晰的二维界面中完成。

## 7 二维书架首页

### 7.1 默认首页结构

用户进入二维书架后，第一屏优先显示：

1. 正在读。
2. 最新导入。

两个区域都以分层实体书架呈现。每层约显示 4–5 本书，根据窗口宽度自适应，不使用普通卡片瀑布流替代真实书架感。

### 7.2 书籍展示

每本书至少显示：

- 封面。
- 书名。
- 阅读状态。
- 必要时显示阅读进度或待补正文状态。

正在读的书可通过轻微前移、柔和光效或进度标记突出，但不得使用营销式推荐标签或夸张动画。

### 7.3 书架内容规则

- 主书架只显示经过用户明确确认、已经进入个人知识体系的书。
- 主书架可以包含待读、正在读和已读三种状态。
- 已读书不会自动移入隐藏归档，因为它仍属于个人知识体系。
- 没有本地正文但经过确认的书可以上架，并显示待补正文。
- 未经确认的微信读书或豆瓣条目不得出现在主书架。
- 空书架只显示简洁的导入入口，不使用热门书籍或推荐内容填充。

### 7.4 顶部入口

书架顶部只保留必要功能：

- 搜索。
- 分类。
- 自定义书单。
- 红心书架。
- 导入书籍。
- 阅读记录。
- 返回书房。

管理入口不得压过书架和封面本身。

## 8 阅读状态

### 8.1 状态定义

- 待读：已经确认进入个人知识体系，但尚未开始正文阅读。
- 正在读：已经打开正文并产生实际阅读进度。
- 已读：用户确认已经完成阅读。

### 8.2 自动状态规则

- 新收录书籍默认标记为待读。
- 首次打开正文并产生有效阅读进度后，自动变为正在读。
- 阅读到正文 95% 时，提示用户是否标记为已读。
- 系统不得在没有用户确认的情况下强制将书标记为已读。
- 用户可以随时手动修改状态。
- 已读书重新打开后不自动改回正在读；如用户开始重读，可主动开启重读记录。

### 8.3 待补正文

- 待读或已读书可以没有本地正文。
- 点击待补正文的书时，提供匹配本地 EPUB/PDF 和前往合法外部阅读入口。
- 后续导入本地文件时，系统优先关联到已有书籍实体，不重复创建封面。

## 9 默认分类、标签和书单

### 9.1 默认分类

系统提供书店式主分类：

- 文学。
- 中国文学。
- 外国文学。
- 小说。
- 诗歌与散文。
- 历史。
- 社会科学。
- 哲学与思想。
- 传记。
- 艺术。
- 绘画与设计。
- 摄影。
- 影视与戏剧。
- 科普与自然。
- 生活。
- 绘本。
- 工具书。
- 其他。

### 9.2 分类规则

- 每本书只有一个主分类。
- 系统可根据书目元数据提供主分类建议。
- 用户可以修改系统建议。
- 题材、时代、地域、主题等交叉属性使用标签表达。
- 分类调整只改变查看入口，不复制书籍实体。

### 9.3 红心书架

- 用户可以为书籍点红心。
- 红心表示精选库中的最爱，与阅读状态分开。
- 红心书架显示全部被用户主动标记的书。
- 取消红心不删除书籍、进度或笔记。

### 9.4 自定义书单

- 用户可以创建、重命名和删除个人书单。
- 同一本书可以加入多个自定义书单。
- 自定义书单用于个人主题组合，例如今年重读、女性写作或旅行前阅读。
- 删除书单只删除组织关系，不删除书籍实体。
- 默认分类负责稳定定位，自定义书单负责个人化组合。

## 10 本地书籍导入

### 10.1 支持格式

- EPUB。
- 文字版 PDF。
- 已有 Markdown 和 TXT 作为兼容格式保留。
- 扫描版 PDF 本期不支持 OCR。

### 10.2 导入方式

- 支持选择单个或多个文件。
- 支持选择文件夹并扫描支持格式。
- 导入过程显示扫描、解析、去重和入库进度。
- 单本失败不得中断整个导入任务。

### 10.3 原始文件与解析结果

- 不修改用户原始文件。
- 保存原始文件或可恢复的本地文件引用。
- 保存文件哈希、大小、修改时间和导入时间。
- EPUB 保存目录、章节、封面和正文结构。
- PDF 保留原始页面，同时生成适合纯净阅读的重排文本。
- PDF 中复杂图表、版式或页码引用需要保留回到原始页面的入口。

### 10.4 书目匹配

系统按以下顺序识别书籍：

1. 读取 EPUB 或 PDF 内嵌元数据。
2. 读取 ISBN。
3. 根据书名、作者、出版社和出版年份检索正规书目源。
4. 计算候选版本置信度。
5. 高置信度自动关联，低置信度进入待确认。

不得因网络匹配而覆盖用户已经确认的书名、作者、版本或封面。

## 11 微信读书导入

### 11.1 导入范围

- 第一版导入微信读书书单的书目结构和元数据。
- 不复制受版权保护的正文。
- 导入方式必须使用官方授权能力、用户主动导出的个人数据或其他合法方式。
- 不要求用户逐本粘贴链接。

### 11.2 临时审核流程

1. 读取书单中的书名、作者、封面和可用标识符。
2. 条目进入一次性临时审核页。
3. 用户选择真正要纳入个人知识体系的书。
4. 用户确认后，选中书籍进入主书架并默认标记为待读。
5. 未选择条目不进入永久书库。
6. 审核完成后，临时列表可清空，不形成长期稍后再看清单。

### 11.3 正文处理

- 已匹配本地 EPUB/PDF 的书可直接阅读。
- 没有本地正文的书显示待补正文。
- 点击时可匹配本地文件或前往微信读书。
- 不尝试绕过微信读书账号权限或 DRM 获取正文。

## 12 豆瓣已读导入

### 12.1 产品目的

豆瓣导入用于迁移用户已经完成的阅读历史，并从中选择真正属于个人知识体系的书。它不是批量寻找电子书文件的工具。

### 12.2 接入原则

- 优先使用豆瓣正式授权接口或用户主动导出的个人数据文件。
- 没有正式授权时，不在产品内自动登录豆瓣或批量爬取页面。
- 旧版豆瓣 API 或第三方抓取接口不能作为稳定生产依赖。
- 开发评审时必须确认可用的合法导入方式。

### 12.3 高分预选流程

1. 读取用户已读书目、个人评分和必要元数据。
2. 四星、五星书籍默认选中。
3. 其他书籍默认不选，用户可以手动补选。
4. 用户一次性审核并确认。
5. 只有确认条目进入个人书架。
6. 导入后的书默认标记为已读，并保留原完成时间、评分或个人短评中的用户自有信息。

### 12.4 已读书与正文

- 已读书不要求立即关联本地 PDF 或 EPUB。
- 已读记录可以仅包含书目、状态、评分、读完时间和用户自己的评价。
- 用户以后需要重读时，再匹配本地正文或合法阅读入口。
- 导入本地文件后，通过 ISBN 优先，书名、作者和出版社辅助关联。
- 系统不得全网搜索或下载受版权保护的 PDF、EPUB 或 Markdown 正文。

## 13 纯净阅读器

### 13.1 总体布局

阅读器以正文为视觉主体。管理、推荐、分类和外部书籍信息在阅读过程中默认隐藏。

主要区域包括：

- 可收起的左侧工具栏。
- 中央正文阅读区。
- 低干扰的阅读进度和翻页区域。
- 必要时出现的选中文本工具条。

### 13.2 左侧工具栏

左侧工具栏包含：

- 目录。
- 书签。
- 划线与笔记。
- 全文搜索。
- 阅读统计。
- 阅读设置。
- 返回书架。

工具栏默认保持窄栏状态。点击图标后打开对应侧栏；再次点击或点击正文区域后收起。

### 13.3 目录

- EPUB 使用原始目录结构。
- PDF 重排版使用原始目录、书签或章节识别结果。
- 目录支持展开和折叠层级。
- 点击目录项后跳转并更新阅读位置。
- 目录跳转不得改变用户当前排版设置。

### 13.4 阅读主题

提供以下主题：

- 白色日间。
- 米白护眼。
- 浅绿色。
- 深色夜间。
- 跟随系统。

主题切换实时生效，并保证正文、链接、划线和笔记标记具有足够对比度。

### 13.5 字体与排版

提供以下字体选项：

- 系统默认。
- 思源宋体。
- 楷体。
- 方正宋三或经授权的等价宋体。

字体缺失或无授权时自动回退到系统可用字体，不得导致正文乱码。

排版设置包括：

- 字号。
- 行间距。
- 段落间距。
- 页边距。
- 阅读区域宽度。
- 首行缩进。

阅读设置允许保存为全局默认，同时可为单本书保留覆盖设置。

### 13.6 翻页方式

提供：

- 仿真翻页。
- 左右滑动。
- 上下滚动。

切换翻页方式时，应尽量保持当前段落位置，不将用户跳回章节开头。

## 14 PDF 与 EPUB 的差异处理

### 14.1 EPUB

- 支持完整重排。
- 支持字体、字号、行距、页边距和主题调整。
- 支持目录、章节定位、全文搜索和语义索引。

### 14.2 文字版 PDF

- 保存原始 PDF 页面。
- 提取正文生成重排阅读版。
- 重排版支持字体、字号、行距、页边距和主题调整。
- 复杂图表、图片、脚注或页面结构可能无法完整重排时，允许一键查看原始 PDF 页面。
- 笔记和引用应尽量同时保留重排段落位置与原始页码。

### 14.3 扫描版 PDF

- 检测到没有可提取文字时，明确提示扫描版 PDF 本期暂不支持。
- 保留失败原因，不生成空白书籍。
- 后续 OCR 作为独立版本规划，不在本期静默执行。

## 15 书签、划线与笔记

### 15.1 书签

- 用户可以在当前位置添加或取消书签。
- 书签保存书名、章节、段落位置、原始页码和创建时间。
- 书签可在当前书中查看，也进入统一知识库索引。

### 15.2 划线

- 用户选择正文后可以划线。
- 提供有限的颜色或样式，避免将阅读器变成复杂标注工具。
- 划线保存原文、上下文、位置和来源。
- 删除划线时，应明确处理其关联笔记，不得静默丢失批注。

### 15.3 笔记

- 用户可以为划线添加笔记，也可以添加当前位置笔记。
- 笔记自动保存书名、作者、章节、原文、页码或段落定位和时间。
- 原文、用户批注和系统生成内容分别存储和显示。
- 所有笔记自动进入左侧知识库，无需用户再次收录。

### 15.4 原文回跳

- 从当前书笔记面板点击记录，可回到原文位置。
- 从全局知识库点击记录，也必须回到原书原位置。
- 如果本地文件暂时丢失，保留笔记和定位信息，并提示重新关联文件。

## 16 阅读统计

### 16.1 展示指标

- 当前阅读百分比。
- 已累计阅读时长。
- 本次阅读时长。
- 预计剩余阅读时间。
- 预计完成所需时长或日期。
- 书签数量。
- 划线数量。
- 笔记数量。

### 16.2 计时规则

- 仅在应用处于前台且阅读页面活跃时累计。
- 长时间无操作后暂停计时。
- 页面隐藏、应用最小化或电脑休眠时不累计。
- 阅读时长按书籍和阅读会话分别保存。

### 16.3 预计剩余时间

- 根据剩余正文长度和用户近期实际阅读速度估算。
- 首次阅读且缺少个人数据时可使用保守默认值。
- 估算值应明确为预计，不显示伪精确到分钟的结果。

## 17 全文搜索与语义搜索

### 17.1 搜索类型

系统同时提供：

- 关键词全文搜索。
- 语义搜索。

关键词搜索用于精确查找字词、短语、人名和原文。语义搜索用于查找措辞不同但含义相关的段落、划线和笔记。

### 17.2 搜索范围

搜索分为三级：

1. 当前书：在阅读器内默认搜索当前书正文、划线和笔记。
2. 休闲书库：在右侧书架中搜索全部休闲书籍。
3. 全局知识库：在左侧知识库中搜索休闲书籍、学术资料、划线、笔记和书签。

### 17.3 搜索结果

每条结果至少显示：

- 结果类型。
- 书名或资料名。
- 章节。
- 原文片段。
- 页码或段落位置。
- 匹配方式。

精确命中与语义相关结果必须使用不同标识。语义结果不得伪装成原文精确命中。

### 17.4 来源回跳

- 有正文的结果可直接回到原文位置。
- 只有书目记录的结果进入书籍详情。
- 搜索结果不得只显示 AI 总结而无法查看原文。
- PDF 结果应尽量同时提供重排位置和原始页码。

### 17.5 索引策略

- EPUB 与文字版 PDF 的重排正文建立全文索引。
- 书签、划线和笔记建立统一索引。
- 索引任务增量执行，不在每次启动时全部重建。
- 索引失败不影响普通阅读，可对单本书重试。
- 删除书籍时需要根据用户选择处理正文索引、笔记索引和知识库记录。

## 18 语义搜索隐私

### 18.1 默认本地

- 语义索引和查询默认在本地执行。
- 书籍正文、学术资料和私人笔记默认不上传。
- 首次索引可以在后台执行，并显示进度、占用空间和失败项。

### 18.2 云端增强

- 云端增强默认关闭。
- 用户主动开启前，必须说明上传的数据类型、用途和服务方。
- 只上传完成当前查询所必需的最小片段。
- 用户可随时关闭云端增强。
- 关闭云端增强后，搜索恢复本地模式，不影响已有书籍和笔记。
- 云端结果也必须保留原文与来源回跳。

## 19 数据模型建议

开发实现中至少区分以下对象：

- BookWork：作品层书籍实体。
- BookEdition：具体版本、出版社、出版年和 ISBN。
- ReadingAsset：本地 EPUB、PDF、兼容文本或合法外部阅读入口。
- ReadingRecord：待读、正在读、已读、进度和阅读时长。
- Category：系统主分类。
- Tag：交叉主题标签。
- BookList：用户自定义书单。
- Favorite：红心关系。
- Bookmark：书签。
- Highlight：划线。
- Note：用户笔记。
- ImportBatch：一次本地或外部导入任务。
- SearchIndexRecord：全文与语义索引状态。

一本书籍实体可以关联多个版本和阅读文件，但不得因为不同来源重复生成多本书。

## 20 去重与版本关联

### 20.1 去重优先级

1. ISBN 完全一致。
2. 外部来源稳定 ID 一致。
3. 标准化书名、作者、出版社和出版年高度一致。
4. 用户人工确认。

### 20.2 版本关系

- 同一作品的不同译本、修订版和出版社版本保留为不同 BookEdition。
- 用户阅读记录需要指向实际阅读版本。
- 如果无法确认是否同一版本，不自动合并。
- 人工合并或拆分必须保存审计记录，可撤销。

## 21 异常与失败处理

- 本地文件丢失：保留书目、进度、笔记和索引记录，提示重新关联。
- EPUB 解析失败：保留原件和错误原因，允许重试。
- PDF 无可提取文字：提示扫描版暂不支持，不创建空正文。
- 外部平台连接失效：不删除已经确认进入书架的书。
- 书目匹配不确定：进入待确认，不静默采用错误版本。
- 封面获取失败：使用可替换默认封面，不阻塞入库。
- 全文索引失败：普通阅读继续可用，允许单本重建。
- 语义索引失败：关键词搜索继续可用，并显示语义搜索暂不可用。
- 批量导入部分失败：完成其余书籍并输出失败清单。
- 应用异常关闭：恢复最近保存的阅读位置、设置和未完成笔记草稿。

## 22 视觉与交互约束

- 延续赛博书房当前深色沉浸式视觉语言，但阅读正文区域以长时间舒适阅读为优先。
- 书架首页应呈现真实分层书架感，不使用通用电商或内容平台卡片流。
- 每层约 4–5 本书，封面不得相互遮挡或溢出层板。
- 书名可读，长标题应采用合理换行或省略，不与封面重叠。
- 阅读器不得长期显示推荐、排行榜、营销横幅或社交动态。
- 左侧工具栏默认收起，避免压缩正文。
- 日间、护眼和夜间主题均需检查文字、划线和链接对比度。
- 仿真翻页动效不得牺牲性能、可访问性或当前位置稳定性。
- 视觉调整不得破坏现有返回书房、知识库和阅读进度能力。

## 23 验收标准

### 23.1 空间入口

- [ ] 右侧书架明确进入休闲阅读模块。
- [ ] 左侧书架下层可进入学术资料知识库。
- [ ] 左侧书架、唱片机和影碟机的点击热区互不重叠。
- [ ] 关闭阅读器后可返回原三维位置。

### 23.2 书架首页

- [ ] 首屏优先显示正在读和最新导入。
- [ ] 每层在常用窗口宽度下约显示 4–5 本书。
- [ ] 每本书显示封面、书名和阅读状态。
- [ ] 未经确认的外部书目不会进入主书架。
- [ ] 待补正文的书可进入书架并显示明确状态。
- [ ] 红心、分类和自定义书单不会复制书籍实体。

### 23.3 状态与分类

- [ ] 新收录书默认待读。
- [ ] 开始正文阅读后自动变为正在读。
- [ ] 阅读至 95% 时询问是否标记已读。
- [ ] 每本书只有一个主分类。
- [ ] 同一本书可以加入多个自定义书单。
- [ ] 红心与阅读状态彼此独立。

### 23.4 本地导入

- [ ] 支持 EPUB 和文字版 PDF。
- [ ] 旧版 Markdown、TXT 和已导入书籍继续可读。
- [ ] 不修改用户原始文件。
- [ ] PDF 同时保留原始页面和重排阅读版。
- [ ] 扫描版 PDF 得到明确提示，不生成空白正文。
- [ ] 同一书籍重复导入优先关联版本，不重复创建。

### 23.5 外部导入

- [ ] 微信读书书单先进入临时审核页。
- [ ] 未确认的微信读书条目不会进入永久书架。
- [ ] 豆瓣四星、五星已读书默认预选。
- [ ] 豆瓣其他书籍默认不选但可手动补选。
- [ ] 外部导入不自动下载受版权保护的正文。
- [ ] 已读书可以在没有正文文件的情况下保留完整阅读记录。

### 23.6 阅读器

- [ ] 左侧工具栏可收起。
- [ ] 目录、书签、笔记、搜索、统计和设置均可正常打开。
- [ ] 支持白色、米白、浅绿、夜间和跟随系统主题。
- [ ] 支持系统默认、思源宋体、楷体和授权宋体。
- [ ] 支持字号、行距、段距、页边距、阅读宽度和首行缩进。
- [ ] 支持仿真翻页、左右滑动和上下滚动。
- [ ] 切换排版或翻页方式时保持当前阅读位置。

### 23.7 笔记与知识库

- [ ] 书签、划线和笔记自动进入统一知识库。
- [ ] 每条记录保留书名、章节、原文和位置。
- [ ] 从知识库可回到原书原位置。
- [ ] 原文、用户批注和系统生成内容分开存储。
- [ ] 本地文件丢失时笔记不丢失。

### 23.8 搜索

- [ ] 当前书、休闲书库和全局知识库均可搜索。
- [ ] 同时支持关键词全文搜索和语义搜索。
- [ ] 精确命中与语义相关结果有明确区别。
- [ ] 搜索结果显示原文片段、章节和位置。
- [ ] 有正文的结果可回到原文。
- [ ] 语义索引失败时关键词搜索仍可用。
- [ ] 默认本地搜索不会上传书籍和笔记。

### 23.9 视觉与稳定性

- [ ] 书架封面、书名和层板无重叠或溢出。
- [ ] 阅读正文在不同主题和窗口尺寸下清晰可读。
- [ ] 左侧工具栏展开时不遮挡关键正文。
- [ ] 大量书籍通过分页、懒加载或虚拟化保持流畅。
- [ ] 至少完成书架首页、分类、红心、外部审核、阅读器、搜索结果和异常状态的截图级检查。

## 24 建议实施阶段

### 阶段一 数据模型与旧书库迁移

- 建立作品、版本、阅读文件、阅读记录和知识记录的分层模型。
- 迁移旧版 Markdown、TXT 和 PDF 书籍。
- 迁移进度、笔记和原文定位。
- 建立备份、回滚和迁移报告。

### 阶段二 空间入口与书架首页

- 划分左右书架职责和点击热区。
- 实现正在读、最新导入和分层书架。
- 实现状态、分类、标签、红心和自定义书单。

### 阶段三 EPUB 与 PDF 阅读

- 接入 EPUB 解析和资源加载。
- 改进 PDF 原始页面与重排正文双模式。
- 实现阅读位置、设置和翻页方式持久化。

### 阶段四 书签、划线、笔记与统计

- 实现标注和当前书笔记面板。
- 自动同步到统一知识库。
- 实现阅读时长和剩余时间估算。

### 阶段五 全文与语义搜索

- 建立当前书、休闲书库和全局知识库三级索引。
- 实现精确搜索、语义搜索和原文回跳。
- 实现本地默认与可选云端增强。

### 阶段六 外部书目导入

- 实现微信读书临时审核流程。
- 在获得合法数据入口后实现豆瓣已读高分预选流程。
- 实现书目去重、版本关联和待补正文。

### 阶段七 验证与交付

- 验证旧数据迁移、书籍去重和版本关联。
- 验证 EPUB、文字版 PDF 和扫描版 PDF 异常提示。
- 验证阅读位置、笔记回跳和索引恢复。
- 完成常用窗口尺寸与主题的截图级视觉检查。

## 25 开发评审时必须确认的事项

1. 当前书库、笔记、进度和知识库数据的实际保存位置。
2. EPUB 解析、资源隔离和脚本安全方案。
3. PDF 重排正文与原始页码之间的定位映射方式。
4. 微信读书是否提供可合法使用的授权或用户数据导出方式。
5. 豆瓣是否能够获得书面授权，或是否存在合规的用户个人数据导入文件。
6. Google Books、Open Library 等书目源的调用限制、缓存和封面许可。
7. 思源宋体、楷体和方正宋三等字体的安装、打包和授权方式。
8. 本地全文索引和语义向量索引的存储空间、增量更新与重建策略。
9. 云端增强使用的服务方、数据范围、隐私说明和关闭机制。
10. 大型 EPUB、长篇 PDF 与大量书籍时的性能预算。

## 26 外部能力与版权边界参考

- 豆瓣官方历史客户端仓库已经归档，旧版 API 不应直接视为当前稳定生产接口：<https://github.com/douban/douban-client>
- 豆瓣法律声明对条目信息使用、衍生应用和数据采集有明确限制；正式接入需获得授权：<https://www.douban.com/about/legal?page=2025-05-27>
- Google Books API 可按书名、作者、ISBN 等查询书目，并通过 accessInfo 区分可预览、可购买或可合法下载的内容：<https://developers.google.com/books/docs/v1/using>
- Open Library Books API 区分作品与具体版本，可按 ISBN 查询版本和封面：<https://openlibrary.org/dev/docs/api/books>
- Open Library Read API 可根据 ISBN 等标识符返回合法在线阅读或借阅入口：<https://openlibrary.org/dev/docs/api/read>

这些接口用于书目匹配、版本识别、封面补充和合法阅读入口判断，不用于自动搜索或下载受版权保护的商业书籍正文。
