## 2 设计结论

左侧书架下层进入独立的学术文献库。该模块以 Aura 已有的数据流程、阅读批注、引用生成和 Word 写入能力为功能基线，但不直接把 Aura 网页作为外部页面嵌入赛博书房，也不只做外观换皮。

优化方向是：

1. 保留 Aura 已经成熟的文献导入、文献库、阅读批注、文献笔记、写作项目、CSL 引用和 Word／WPS 写入链路。
2. 将界面、导航、数据接口和视觉语言重构为赛博书房的一部分。
3. 增加 Zotero 本地文献库手动单向同步、Crossref 论文检索和扫描版 PDF 主动 OCR。
4. 将文献摘录、批注和笔记输出到统一知识层，为以后与休闲书籍、电影、音乐和其他个人记录合并做准备。
5. 保留原始文件、题录来源、页码、引用版本和人工修正，使所有研究结果可回查、可复核、可迁移。

## 3 产品定位

学术文献库是赛博书房的研究工作台，用于管理学术专著、论文、报告和研究资料，完成从书目发现到 Word 引用的闭环：

> 找到书目 → 导入全文 → 核对版本 → 阅读与批注 → 写文献笔记 → 加入写作项目 → 生成引用 → 写入 Word → 沉淀到个人知识库

它不是普通文件夹、单纯 PDF 阅读器或无限收藏箱。进入文献库的资料应服务明确的研究、写作、教学或长期知识积累。

## 4 目标与非目标

### 4.1 目标

- 从三维书房清晰进入左侧学术文献库。
- 保留 Aura 的十个研究模块和完整工作流。
- 支持 PDF、Word、扫描版 PDF、RIS、BibTeX 和外部书目导入。
- 连接 Zotero 本地生态，手动单向同步文献库、分类和附件状态。
- 使用豆瓣、Open Library 和 Crossref 检索不同类型的书目。
- 支持原页阅读、文字与区域批注、OCR、Markdown 文献笔记。
- 支持写作项目、CSL 样式、脚注、文内引用和参考文献表。
- 支持安全的 DOCX 副本模式和 Word／WPS 实时模式。
- 将研究成果自动进入统一知识层并保留原文回跳。
- 支持完整备份、回收站、迁移和可恢复长任务。

### 4.2 非目标

- 第一版不做 Zotero 双向同步。
- 不直接修改 Zotero SQLite 数据库。
- 不自动覆盖 Zotero 或赛博书房中的人工修正。
- 不用 AI 自行补全缺失书目信息或生成不可核对的引用。
- 不覆盖原始 PDF、Word 或 DOCX 文稿。
- 不把索引、Excel 或导出文件作为唯一恢复数据源。
- 不在第一版重做整个个人知识库前端；只建立统一知识接口与数据边界。
- 不绕过豆瓣、数据库或出版平台的访问与版权限制。

## 5 现状与差距

### 5.1 赛博书房当前能力

当前成品应用已具备：

- 本地 Markdown、TXT 和文字版 PDF 导入。
- 基础阅读进度、摘录和批注。
- 简单知识库检索。
- Markdown 摘录导出。
- 三维书房中的书库、知识库和创作台入口。

### 5.2 Aura 功能基线

Aura 指南显示其已具备：

- PDF／Word 全文、RIS 题录和豆瓣链接导入。
- 豆瓣与 Open Library 书目搜索。
- 封面视图、清单视图、分类和写作项目。
- 逐页阅读、文字或区域批注。
- 按文献保存 Markdown 笔记。
- 引用序列、CSL 样式、脚注与参考文献预览。
- DOCX 副本写入和 Word／WPS 实时连接。
- 样式管理、回收站、备份与迁移。

### 5.3 本次新增

- Zotero Local API 手动单向同步。
- BibTeX 导入与回导。
- Crossref 论文、会议论文和 DOI 检索。
- 扫描版 PDF 主动 OCR。
- 全文与语义搜索的统一索引接口。
- 书籍、电影、音乐与文献共用的知识记录协议。

## 6 三维空间入口

### 6.1 热区划分

- 左侧书架下层设置学术文献库热区。
- 热区避开上方唱片机和影碟机。
- 唱片机、影碟机和学术文献库分别提供明确悬停提示。
- 不使用覆盖整个左侧书架的大范围热区。

### 6.2 进入和返回

- 点击后镜头移动到左侧书架下层。
- 短暂显示书架或档案灯光反馈。
- 随后打开二维研究工作台。
- 关闭工作台后回到进入前的三维位置和视角。

## 7 研究工作台信息架构

### 7.1 左侧模块栏

固定包含：

1. 文献库
2. 导入文献
3. 搜索书目
4. 阅读与批注
5. 文献笔记
6. 引用与参考文献
7. 文稿引用助手
8. 样式管理
9. 回收站
10. 备份与设置

### 7.2 顶部上下文

顶部显示：

- 当前写作项目。
- 当前文献。
- 全局搜索。
- Zotero 连接与最近同步状态。
- 当前长任务进度。
- 返回书房。

### 7.3 项目原则

- 写作项目是引用序列、样式和任务文献的组织单位。
- 文献入库不要求先选择项目。
- 同一文献可以加入多个项目。
- 每个项目独立保存引用顺序、页码、样式和文稿副本。

## 8 文献库

### 8.1 视图

- 封面视图：适合专著和图书。
- 清单视图：适合论文、报告和批量处理。
- 专著没有封面时显示白底题名卡，不自动生成装饰图。
- 论文卡片突出题名、作者、年份、期刊和 DOI。

### 8.2 分类与筛选

- 固定分类：专著、论文。
- 用户可以创建自定义分类。
- 支持题名、作者、年份、关键词、DOI、ISBN、期刊、出版者和标签筛选。
- 分类、标签和写作项目不复制文献实体。

### 8.3 书目与全文分离

- 只有题录的文献可以进入文献库。
- PDF／Word／扫描件作为全文附件关联到书目。
- 解除全文关联不删除书目、笔记和批注。
- 同一文献可关联多个版本或附件，但需要明确主版本。

## 9 导入文献

### 9.1 支持入口

- PDF、Word 和扫描版 PDF。
- Zotero 本地文献库与分类。
- RIS。
- BibTeX。
- 豆瓣图书链接。
- DOI、ISBN 和普通书目链接。
- 手动录入或粘贴书目信息。

### 9.2 批量任务

批量导入显示：

- 扫描数量。
- 支持与跳过数量。
- 解析进度。
- 已匹配数量。
- 重复数量。
- 待确认数量。
- 成功与失败数量。
- 当前处理文件。

单条失败不终止整个任务。任务状态和失败项写入可续跑状态文件或数据库记录。

### 9.3 去重顺序

1. DOI 完全一致。
2. ISBN 与版本一致。
3. Zotero item key 与库 ID 一致。
4. 文件哈希一致。
5. 标准化题名、作者、年份和期刊高度一致。
6. 人工确认。

不确定时不自动合并。

## 10 书目检索与来源职责

### 10.1 豆瓣

- 用于中文专著和原始条目来源。
- 读取作者、出版社、年份、版次、ISBN 和封面等合法可用字段。
- 正式接入需要获得授权或使用用户主动提供的数据。
- 豆瓣链接只记录书目来源，不下载全文。

### 10.2 Open Library

- 用于外文专著、ISBN、作品与版本关系和封面。
- 区分 Work 与 Edition。
- 用户选择实际使用的版本后再入库。

### 10.3 Crossref

- 用于期刊论文、会议论文、专著章节和 DOI。
- 支持按 DOI 精确获取，或按题名、作者和期刊检索候选。
- 使用 polite pool，提供明确 User-Agent 和联系邮箱。
- 缓存响应并按状态码退避，避免高频重复请求。
- 摘要可能受出版者或作者版权约束，不默认作为可自由再分发内容。

### 10.4 候选审核

- 搜索结果先进入候选列表。
- 显示题名、作者、年份、出版社或期刊、DOI／ISBN、版本与来源。
- 多个版本不能静默合并。
- 用户核对后才加入正式文献库。

## 11 Zotero 单向同步

### 11.1 连接方式

- 第一选择：Zotero Local API。
- Zotero 桌面端需要由用户开启允许本机应用通信。
- 读取本地 API 时不需要网络或远程 API 密钥。
- 不直接修改 Zotero SQLite 数据库。
- RIS／BibTeX 继续作为离线兜底。

### 11.2 同步范围

- 文献题录。
- Zotero 分类和子分类。
- 标签。
- 附件元数据和允许访问的本地附件。
- 外部 ID 与 item key。
- 最近修改版本。

### 11.3 同步方向

- 第一版仅从 Zotero 进入赛博书房。
- 用户手动触发，不后台自动同步。
- 不把赛博书房修改自动写回 Zotero。

### 11.4 冲突保护

Zotero 可以更新原始题录字段和附件状态，但不得覆盖：

- 赛博书房个人标签。
- 写作项目归属。
- 摘录和批注。
- 文献笔记。
- 人工修正字段。
- 统一知识关系。

同一字段发生冲突时进入待确认，并显示两侧值、修改时间和来源。

### 11.5 增量同步

- 保存 Zotero 实例标识、item key 和对象版本。
- 再次同步只读取新增或变化项目。
- 删除或移出 Zotero 分类的项目不自动从赛博书房删除。
- 同步结果显示新增、更新、冲突、跳过和失败数量。

## 12 全文处理与 OCR

### 12.1 普通 PDF

- 保留原始 PDF。
- 提取文字、目录和页码映射。
- 建立全文索引。
- 复杂页面仍以原始页图为视觉依据。

### 12.2 Word

- 保留原始 Word 文件。
- 在本机生成阅读副本。
- 原文件不被修改。
- 转换失败时保留原件并记录失败原因。

### 12.3 扫描版 PDF

- 导入时检测是否缺少文字层。
- 不自动启动长时间 OCR。
- 用户主动选择页面范围和语言后开始 OCR。
- 逐页写入 OCR 结果、置信度和状态。
- 支持暂停、恢复和失败重试。
- 原始页图、OCR 文本和人工修正分层保存。
- OCR 文本在界面和搜索结果中明确标识。

## 13 阅读与批注

### 13.1 三栏布局

- 左侧：目录、缩略图、全文搜索和页面跳转。
- 中间：PDF／Word 阅读区。
- 右侧：当前页批注、摘录和文献笔记。
- 两侧可收起，进入专注阅读。

### 13.2 批注类型

- 文字划线。
- 区域框选。
- 页级批注。
- 书签。
- 摘录。
- 个人评论。

### 13.3 定位字段

每条批注保存：

- 文献 ID。
- 版本或附件 ID。
- 页码。
- 文字偏移或图像坐标。
- 原文或页图引用。
- 用户批注。
- 创建和修改时间。
- 原文类型：原生文本、OCR 文本或人工修正。

再次打开文献时可准确回到原位置。

## 14 文献笔记

### 14.1 格式与编辑

- 每份文献拥有独立 Markdown 笔记。
- 支持上传已有 Markdown。
- 支持安全预览，不执行笔记内脚本。
- 自动保存并保留版本记录。
- 支持导出 Markdown。

### 14.2 结构化区块

可选区块包括：

- 摘要。
- 核心问题。
- 主要论点。
- 方法。
- 证据。
- 结论。
- 可引用内容。
- 疑问与反驳。
- 与其他资料的关联。
- 个人判断。

用户可以自由书写，不强制填写模板。

### 14.3 摘录引用

- 插入摘录时自动带入页码和原文定位。
- 修改笔记不会修改原始文献。
- 删除文献时笔记先进入回收站。

## 15 统一知识接口

### 15.1 自动沉淀

摘录、批注和文献笔记自动生成统一知识记录，至少包含：

- 来源模块。
- 文献 ID。
- 题名与作者。
- 原文。
- 页码和定位。
- 用户批注。
- 标签和项目。
- 创建与修改时间。
- 回到原文入口。

### 15.2 类型分离

必须区分：

- 原始文献文本。
- OCR 文本。
- 人工修正文本。
- 用户摘录。
- 用户批注。
- 用户文献笔记。
- AI 建议或摘要。

### 15.3 后续合并

个人知识库前端后续统一整合：

- 学术文献。
- 休闲书籍与阅读笔记。
- 电影与观影感想。
- 音乐收藏与相关记录。

各模块共用搜索和关系层，但保留各自原始文件与专业工作流。

## 16 搜索

### 16.1 关键词搜索

- 当前文献全文、OCR、批注和笔记。
- 文献库题录、全文、笔记、标签和项目。
- 全局知识库跨模块检索。

### 16.2 语义搜索

- 默认在本地建立索引。
- 结果显示原文片段、来源类型、文献题名和页码。
- 点击结果回到原文。
- 语义相关与精确命中分开标识。
- OCR 结果显示识别文本标记。

### 16.3 云端增强

- 默认关闭。
- 开启前说明服务方、上传范围和用途。
- 只上传当前查询需要的最小片段。
- 关闭后恢复本地模式。

## 17 引用与参考文献

### 17.1 项目数据

每个写作项目独立保存：

- 项目文献集合。
- 引用序列。
- 引用页码。
- 引用样式。
- 脚注预览。
- 文内引用预览。
- 参考文献表预览。

### 17.2 引用操作

- 选择项目文献作为引用。
- 填写印刷页码、卷期、章节或定位说明。
- 调整引用顺序。
- 复制单条引用、脚注列表或参考文献表。
- 导出引用与参考文献。

### 17.3 缺失字段

- 缺失作者、年份、出版社、页码等字段时明确提示。
- 不用 AI 自行补全无法核验的书目信息。
- 用户修正保存为人工覆盖，保留原始来源值。

## 18 CSL 样式管理

### 18.1 内置样式

第一版至少提供：

- GB/T 7714。
- Chicago。
- APA。
- MLA。
- 常用中文脚注体例。

### 18.2 在线样式目录

- 支持按期刊或样式名检索。
- 用户确认后导入。
- 已导入样式离线可用。
- 保存样式名称、版本、来源和文件哈希。
- 用户可移除非默认样式。

### 18.3 渲染原则

- 引用由结构化书目字段和 CSL 样式渲染。
- 渲染在本机完成。
- 同一项目记住自己的样式。
- 样式切换实时更新预览，不修改原始书目。

## 19 文稿引用助手

### 19.1 本地 DOCX 副本模式

- 作为默认推荐模式。
- 选择未加密、未受保护的 DOCX。
- 读取正文段落并让用户选择插入位置。
- 添加、更新或删除引用时生成新副本。
- 原始文稿永不被静默修改。
- 副本按时间和版本保存在已处理目录。
- 文稿变化后必须重新读取和重新定位。

### 19.2 Word／WPS 实时模式

- 用户先保存已打开的 DOCX。
- 在正文、脚注或尾注处放置光标。
- 赛博书房记录位置后插入或更新引用。
- 切换窗口不丢失记录位置。
- 连接失败时保留引用参数并回退到副本模式。

### 19.3 写入边界

- 不自动重写正文。
- 不自动调整全文结构。
- 不在未确认时批量替换现有脚注。
- 每次写入保存文献 ID、页码、样式、文稿版本和操作结果。

## 20 本地优先与安全

- 全文、OCR、批注、笔记、项目和文稿默认本地保存。
- Zotero Local API 只绑定本机回环地址，不对外暴露端口。
- 不直接写 Zotero SQLite。
- 远程 Zotero Web API 如后续启用，令牌使用系统安全存储。
- 日志不记录全文、令牌或私人笔记内容。
- Markdown 预览不执行脚本。
- EPUB、PDF 和 Word 解析在受控环境中运行。

## 21 备份、回收站与迁移

### 21.1 完整备份

至少包含：

- 书目与来源。
- 分类、标签和项目。
- 全文文件与哈希。
- OCR 文本与人工修正。
- 批注、摘录和文献笔记。
- 引用序列和 CSL 样式。
- 文稿副本索引。
- Zotero 同步映射。
- 搜索索引重建信息。

### 21.2 回收站

- 删除文献后，书目、全文、笔记和批注一起进入回收站。
- 支持完整恢复。
- 永久删除前明确列出影响范围。
- 永久删除后清理全文、派生文本和搜索索引。

### 21.3 迁移

- 支持导出完整工作区备份。
- 恢复时校验清单、哈希和版本。
- 搜索索引可重建，不作为唯一数据源。
- 迁移报告列出成功、跳过和失败项。

## 22 异常处理

- Zotero 未运行：提示启动 Zotero 或使用 RIS／BibTeX。
- Zotero Local API 未开启：给出明确开启路径。
- Zotero 同步失败：保留本地数据和同步游标，可重试。
- 豆瓣不可用：允许手动录入或改用其他书目源。
- Open Library 或 Crossref 不可用：显示来源状态并退避重试。
- OCR 失败：保留原始页图和已完成页面，允许按页重试。
- 文件移动：保留书目、笔记和批注，提供重新关联。
- Word 实时连接失败：回退副本模式。
- 文稿变化：停止写入，要求重新读取和定位。
- 索引失败：普通阅读和关键词基础搜索继续可用。
- 单条导入失败：继续处理其他项目并输出失败清单。
