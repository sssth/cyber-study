# 地球仪个人足迹闭环：实施与验收

本次实现第二阶段的个人照片整理闭环，不包含第三阶段的 3D 地球、连续转场或旅程。

## 已实现

- Electron 本地记忆库：`userData/memory-globe/library.json` 与 `assets/`，原图、1800 像素以内预览、360 像素以内缩略图分开保存，索引采用临时文件加重命名写入。
- 单张、多张、递归文件夹导入；单文件上限 80 MB；按 SHA-256 跳过重复；失败逐张报告，成功记录即时持久化；回收站内重复照片提示恢复。
- JPEG EXIF 拍摄日期与 GPS 候选；缺失数据保持未知。其他图片格式可以解码导入，但本轮不解析其 EXIF。HEIC/HEIF 是否成功取决于 Electron/系统解码能力，不支持时进入失败报告。
- 待整理、我的足迹、全部照片、回收站；搜索；照片放大与键盘切换；编辑日期和说明。
- 28 个离线城市中心候选，明确标记为近似定位；支持手动经纬度及零度坐标；单张、勾选多张、选择当前筛选结果批量确认。
- 确认 GPS 或手动坐标后才进入足迹；批量操作前显示数量、地点与坐标。修改坐标后回到待确认。
- 软删除和恢复保留记录、图片、地点；本轮没有永久删除入口。
- 完整目录备份含原图、预览、缩略图、坐标和回收站。恢复校验原图哈希、重新生成派生图，按记录 ID 合并，不覆盖现有同编号记录。备份清单最后写入，避免把未完成复制当作可用备份。
- 明确点击“迁移旧版照片”后，逐条迁移原 Local Storage 记录；重复执行不会重复迁移；随机经度丢弃，旧日期待核实；原 Local Storage 保留作为回退，不自动删除。

## 验证

- 8 项 Node 数据测试通过：导入去重与重开、地点确认、回收站、重复迁移、异常坐标与解码失败、完整备份空库恢复及合并、损坏备份与路径攻击、损坏索引保护、EXIF 字段（含南纬西经）。部分场景合并在同一测试中。
- Playwright 浏览器界面测试（虚构照片、模拟桌面接口）：StrictMode 初次加载、城市确认、足迹分类、图片查看与 Esc、回收站恢复通过。
- 截图检查发现并修复共用卡片网格导致文字挤压的问题；照片按钮改用矩形圆角，避免裁成椭圆。
- 隔离的真实 Electron 测试：原生图片解码、文件夹导入、重复与坏图报告、自定义图片协议、真实 IPC、地点写入、完整备份、合并恢复与页面重载全部通过。使用临时测试资料库，未接触用户照片。
- Vite 生产构建通过，仍有原项目的大包体积提示。

## 当前边界

本轮地点整理采用离线城市和经纬度输入；没有平面地图点选或联网地名搜索。坐标确认后的足迹目前以照片卡和坐标展示，真实地球投影属于第三阶段。目录备份未压缩，复制大量原图需要足够磁盘空间。恢复保留当前同编号记录，不能用于覆盖当前编辑或自动找回同编号照片的旧版本。

源码与 dist 已更新；尚未重新打包 release 中的桌面应用。需要重新启动开发版 Electron 才能载入新增桌面接口，单独刷新网页不足以启用。
