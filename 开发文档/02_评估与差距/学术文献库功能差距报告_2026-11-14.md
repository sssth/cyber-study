# 学术文献库功能差距报告

依据[学术文献库优化设计 v1.0](../01_需求与设计/赛博书房学术文献库优化设计_v1.0.md)和[项目功能差距与迭代可行性报告 §3.2](项目功能差距与迭代可行性报告_2026-11-14.md)，核对当前工作区源码。桌面打包版未运行验收。

**当前有可复用的阅读底座。** 书库支持批量导入、保留原始 PDF、提取文字为 Markdown、文件哈希去重；阅读器已有划线、多条批注、原文回跳和 Markdown 导出。当前源码中未见独立研究工作台或可直接整合的 Aura 源码。

| 功能 | 主要差距 |
| --- | --- |
| **研究工作台** | 缺独立的左侧学术书架入口、文献库视图、研究项目上下文和工作台导航。可复用现有场景路由与面板框架。 |
| **题录与附件** | 目前以文件为单位保存。缺独立题录、多附件与版本关系、无全文题录，以及 Word、RIS、BibTeX、DOI／ISBN 导入和候选审核。文件哈希仅能识别内容相同的文件。 |
| **书目检索与 Zotero** | 缺 Crossref、Open Library、图书豆瓣的元数据查询和匹配审核。也缺 Zotero 手动单向增量同步、分类树、附件状态和冲突记录。RIS／BibTeX 是同步之外的导入入口。 |
| **PDF 原页、批注与 OCR** | 当前批注定位在重排段落。缺 PDF 原页、页码与坐标映射、区域批注和 Word 阅读副本。学术库设计要求扫描件由用户主动发起逐页 OCR，并支持暂停、恢复和重试。 |
| **文献笔记与搜索** | 可复用摘录和批注编辑。缺按文献保存的结构化 Markdown 笔记、版本历史、引用回链，以及覆盖题录、全文、笔记和 OCR 的搜索与语义检索。 |
| **引用与文稿** | 缺项目引用序列、CSL 样式、文内引用／脚注／参考文献生成和 DOCX 副本写入。Word／WPS 实时连接需在目标软件上验证。 |
| **备份与恢复** | 通用书库已有本地保存和单书移到系统废纸篓。学术库仍缺题录、附件、笔记及项目的整体备份恢复、应用内回收站和长任务恢复。 |

**建议首轮验收**　用一篇论文走通「题录入库 → 关联 PDF → 原页批注 → 文献笔记 → 生成参考文献并导出」。电子书模块的导入、摘录和导出可复用，学术引用的版本关系与原页定位应优先补齐。Aura 的可用程度需等源码、许可和运行样例确认后再估算。
