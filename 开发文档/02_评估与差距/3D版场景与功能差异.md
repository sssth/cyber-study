# 3D 版 Loft 场景与功能差异

项目现已支持合并后的「3D版Loft」场景包。它保留共用摆位，并加入日间、霓虹夜、雨夜、低光、七个机位、漫游、书房热点和音景混音。下文的日间包说明保留首次导出的操作与原 App 的实现记录。新格式的字段及制作示例见 [场景包制作格式](../../场景包预览工具/场景制作格式.md)。

## 场景包

在「场景包预览工具」选择 `场景包/3D版Loft-日间` 文件夹即可打开。要在书房主程序里使用，把根目录 `scene.config.json` 的 `sceneFolder` 设为 `场景包/3D版Loft-日间`，再重启开发版或重新打包桌面 App。

包内有 `scene.json` 和 26 个可独立摆放的 GLB。房间结构、窗、吊顶、客厅、钢琴区、吧台、阅读区、玄关和日间室外景来自 App 实际生成的场景。晶体、岩石、书桌台面、座椅和显示器沿用 App 中加载成功且在日间可见的模型，显示器的贴图界面也随场景导出。场景包以全景机位起步，模型的旋转和非等比缩放已经写进 GLB，配置中的摆位按现有加载器的规则换算为 X/Z 包围盒中心、Y 底部和 X 轴宽度。

书架、书桌、显示器及对应摆件绑定现有项目的功能 ID。窗户在这份日间包里是展示模型。原 App 的环境贴图、雾、投影光照、精灵光晕、动态雨、日夜按钮和漫游由运行时代码控制。导入后由原项目负责灯光与渲染，日间几何和材质会保留，画面明暗和阴影会有差异。

## 3D 版的功能差异

| 功能 | 3D 版实现 | 当前项目 |
| --- | --- | --- |
| 日间／夜间 | 右下按钮或 L 键，启动为日间。切换背景、雾、曝光和环境反射贴图。日间开启太阳光和阴影、天空补光、地面反弹光及日景楼群，压低夜灯、隐藏霓虹与夜景城市，换地板贴图及材质参数。夜间恢复保存的材质参数与灯光。选择雨夜会自动退出日间。 | 房间灯光、窗外雨和环境音已有各自的开关。 |
| 分区视角 | 全景、书房、客厅、钢琴、吧台、阅读、漫游共七个预设。数字键 1–7 与按钮调用同一切换函数，在约 0.9 秒内用平滑插值更新相机位置、目标和视野。 | 场景包定义一个起始视角，运行时可原地拖动和滚轮缩放。 |
| 第一人称漫游 | 所有机位切换完成后都可走动。拖拽转头，WASD 或方向键水平移动，Q/E 升降，滚轮前后。每帧按时间步更新坐标，使用房间轴对齐边界限制位置。家具几何未参与碰撞判断。 | 主场景相机保持在固定位置。 |
| 夜间主题与音景联动 | 宿主应用提供霓虹夜、雨夜、低光。3D 层观察宿主的场景样式，调灯、雾和地面粗糙度。雨夜时移动线段顶点生成雨幕。宿主 Web Audio 按主题设置雨声、设备低鸣、城市声的混音增益。 | 已有独立雨景、灯光和环境音，操作各开关分别改变对应状态。 |
| 世界坐标热点 | 九个位置每帧投影成屏幕上的点和文字，书房机位显示。点击转发给宿主原有 SVG 或导航按钮，打开已有面板。 | 模型点击直接通过场景包的 feature ID 触发功能，互动菜单也可打开。 |
| 额外空间与摆设 | 客厅、钢琴、吧台、独立阅读角和玄关由脚本生成。钢琴和吧台提供空间布景与预设机位。 | 原有功能面板和互动逻辑可继续使用，包括知识库、音乐、电影、日记、便签、地球仪、抄写、猫和植物。 |

## 实现定位

- 交付 App 的 `Contents/Resources/app/dist/scene3d.js` 中，`setDay`、`applyDay`、`applyState` 控制主题，`VIEWS`、`setView`、`bindControls`、`updateCamera` 控制机位与漫游，`HOTSPOTS`、`updateHotspots`、`trigger` 实现热点。
- 同目录的 `loft_space.js` 中，`buildDaylight` 和 `buildOutside` 建立日间照明与室外景，`prepMaterial` 和 `setDaylight` 保存及切换材质参数。房间结构和各区家具也在此文件中构建。
- 原项目的 `src/scenes/three/Furniture3DLayer.jsx` 负责模型摆位、镜头和渲染，`src/scenes/featureBindings.js` 管理模型功能绑定。要加入日夜切换和漫游，需要扩展这两部分中的场景渲染及相机控制，场景包可提供灯光预设或机位的数据。
