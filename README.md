# 赛博书房 · 本地桌面 Demo

这是一个 Electron + React 的沉浸式阅读应用骨架。第一阶段已经完成：

- 本地桌面窗口
- 书房场景分层结构
- 灯光开关
- 电脑显示器点击入口
- 阅读层占位界面
- 场景 / 声音 / 阅读三层代码分区

## 启动方式

macOS 用户可以直接双击项目根目录下的 `启动赛博书房.command`，Windows 用户双击 `启动赛博书房.bat`。

需要先安装 Node.js 20 或更高版本。

Windows 上的差异：

- 窗口使用系统标题栏（`hiddenInset` 只在 macOS 生效）。
- PDF 导入组件用 `安装 PDF 转换组件.cmd` 安装，脚本会自动查找 `python` / `py`。
- 打包脚本 `package:mac` 仍然只在 macOS 上可用。

安装依赖：

```bash
pnpm install
```

开发模式启动：

```bash
pnpm dev
```

构建并直接运行：

```bash
pnpm start
```

### 打包成 macOS App

在 macOS 上执行：

```bash
pnpm package:mac
```

脚本会自动构建项目，并生成带当日日期的独立应用与可传输 ZIP：

```text
release/mac/赛博书房-2026-11-10.app
release/mac/赛博书房-2026-11-10.zip
```

日期由打包当天自动生成。建议把带日期的 `赛博书房-日期.zip` 发给其他用户；微信等工具通常不能直接发送 `.app` 文件夹。

当前包使用本地 ad-hoc 签名，适合自己电脑运行或可信用户之间分发。如果要分发给别人并减少 Gatekeeper 提示，需要在 Apple Developer 环境中用正式证书签名：

```bash
MAC_CODESIGN_IDENTITY="Developer ID Application: 你的公司名 (TEAMID)" pnpm package:mac
```

也可以把 `assets/icons/app.icns` 放进项目后再打包，脚本会自动替换应用图标。

## 下载场景包

场景资源与源码分开分发，不随仓库下载。默认场景「3D版Loft v0.2」提供两档画质包，**任选其一**下载即可：

👉 **[场景包下载 · GitHub Releases](https://github.com/sssth/cyber-study/releases/tag/scene-pack-loft-v0.2-v2)**

| 压缩包 | 大小 | 说明 |
|--------|------|------|
| `Loft-v0.2-full.zip` | 约 2.08GB | **完整版**：内含低 / 中 / 高三档画质资源，可在应用内随时切换画质 |
| `Loft-v0.2-low.zip` | 约 478MB | **低画质版**：仅低画质资源，体积小、下载快，应用默认即低画质启动 |

安装步骤（两档相同）：

1. 下载其中一个压缩包并解压，得到形如 `Loft-v0.2-场景包-完整版/` 的文件夹（内含 `scene.json`、`models/`、`textures/`、`sounds/`）；
2. 把该文件夹放进项目根目录的 `场景包/` 目录下；
3. 打开 [scene.config.json](./scene.config.json)，把 `sceneFolder` 改为解压出的文件夹名，例如 `"场景包/Loft-v0.2-场景包-完整版"` 或 `"场景包/Loft-v0.2-场景包-低画质版"`；
4. 启动应用。下载完整版的用户可在应用内按需切换低 / 中 / 高画质。

> 旧版三分卷下载方式（models-main / models-shared / extras）已废弃，新压缩包均为自包含单文件。

## 打包场景包预览工具

双击项目根目录的「打包场景包预览工具.command」，或运行 `pnpm package:preview:mac`。打包使用「场景包预览工具」目录里已有的 `web` 网页产物。修改工具源码后，请先在工具目录重新构建网页。

`release/mac` 会生成带日期的预览工具 ZIP。接收方解压后，双击「打开场景包预览.command」，然后在 Chrome 或 Edge 里选择要预览的场景包。启动需要 Node.js，关闭启动窗口即可停止预览。场景包可单独发送。

## 场景深化版说明

右上角「互动菜单」分为「物品互动」和「房间控制」。物品互动包括书库、知识库、音乐、电影、日记、便签、地球仪、打字机、猫和植物。即使房间里没有对应模型，也可从菜单进入。

「房间控制」提供灯光、窗外雨和声音开关。黑曜赛博房间默认开启窗外雨，视角静止时雨也会持续下落。点击该场景的窗户也能开关雨景。底部操作提示会在三秒后自动消失。

## 更换场景包

启动前打开项目根目录的 [scene.config.json](./scene.config.json)，修改 `sceneFolder`。路径相对于项目根目录，应指向直接包含 `scene.json` 的文件夹。例如切换到黑曜赛博房间：

```json
{
  "sceneFolder": "场景包/黑曜赛博房间"
}
```

保存后重新运行 `启动赛博书房.command` 或 `pnpm dev`。要切回原场景，把路径改为 `场景包/赛博书房`。如果你使用的是已打包的 Mac 应用，修改后在项目目录重新运行 `pnpm package:mac` 生成应用。

macOS 打包时会读取当前的 `sceneFolder`，只收录该场景的 `scene.json` 所引用的模型，以及该场景目录中可用的桌面宠物模型。预览图、建模脚本和其他房间的资源会留在项目目录。

场景目录结构、模型摆放和功能绑定见 [场景包制作指南](./场景包预览工具/场景制作格式.md)。

「3D版Loft」在同一包内提供日间、霓虹夜、雨夜、低光和七个分区视角。左下角或数字键 1–7 切机位，右下角或 L 切换日夜。拖动转头，WASD 走动，Q/E 升降。右上角「互动菜单」里的「窗外雨」只在夜间影响画面和音景。开启时显示雨夜，关闭时回到霓虹夜。开启「声音」后，环境音随主题切换。预览工具也可试播。

## 声音系统说明

打开右上角「互动菜单」，在「房间控制」中开启「声音」。环境声音由雨声、设备低鸣和远处城市声混合而成。窗外雨控制画面，声音开关控制环境音。

## 阅读系统说明

在「互动菜单」选择「书库」即可进入阅读书库。应用首次初始化示例时加入五本可删除的示例书：

- 《论语》
- 《呼兰河传》
- 《The Skeptical Chymist》
- 《The Prince》
- 《Oliver Twist》

阅读功能：

- 打开内置示例书
- 「导入文件」支持单选或多选，「导入文件夹」会递归导入子文件夹。支持 Markdown、TXT、PDF。
- 每本书的原件和转换后的 `book.md` 保存在应用数据的 `books` 目录。文字版 PDF 使用 PyMuPDF 和 PyMuPDF4LLM 转成 Markdown，保留可识别的章节。阅读器可按目录跳转，全文检索显示章节路径。扫描件会提示没有可提取的文字。
- 选中同一段落内的文字并保存摘录，阅读器会把下划线写入书稿的 `<u>…</u>` 标记，同时把摘录、批注和标签保存到知识库。
- 首次启用 PDF 导入时运行「安装 PDF 转换组件.command」。需要 Python 3.10 及以上和 pip，依赖安装在应用数据目录。打包版请传入其应用数据目录，例如 `./安装\ PDF\ 转换组件.command "$HOME/Library/Application Support/赛博书房"`。
- 继续上次阅读
- 自动保存阅读进度
- 调整字号和行距
- 返回赛博书房场景

示例素材位于 `assets/default-samples/`。书名、封面与书架摆放随应用一起分发。

## 唱片机在线音乐

在桌面版打开「互动菜单 → 唱片机」，选择 QQ 音乐或网易云音乐，扫码后选择个人歌单并点「导入唱片架」。用唱片架上方的下拉菜单切换歌单。曲目会先显示在列表里，缓存完成后即可播放。未能缓存的曲目会在导入结束后移出列表，并在导入结果中列出原因。重新导入同一个平台的同一张歌单会复用已有缓存。

QQ 音乐连接使用 [Simple Music v2.7.0](https://github.com/Yyyangshenghao/simple-music/tree/v2.7.0) 的部分模块。网易云使用与 [YesPlayMusic](https://github.com/qier222/YesPlayMusic) 相同的 NeteaseCloudMusicApi。上游来源和许可证见 [NOTICE](electron/music/simple-music/NOTICE.md)。

## 水晶聊天（AI 对话，可选）

在「互动菜单 → 水晶球」中提供**可选**的 AI 对话功能，不需要该功能可完全跳过本节，应用其余功能不受影响。想使用时：把项目根目录的 [ai-settings.example.json](./ai-settings.example.json) 复制为 `ai-settings.json`，在对应厂商的 `apiKey` 字段填入你自己的 API Key，并在 `current` 里选择默认厂商和模型即可。`ai-settings.json` 含个人密钥，已被 `.gitignore` 排除，不会被提交。

### 默认低画质打包

双击「打包赛博书房.command」默认只收录低画质模型及其实际依赖；缺少低画质版本的模型沿用原模型。不会修改源场景。应用每次启动使用低画质，不自动测试硬件或恢复上次高画质设置。运行中仍可手动切换画质；低画质安装包不含原尺寸模型，完整场景配置及对应资源可用时才能获得完整高画质素材。


### 单独发布场景资源

GitHub 上的源码与场景资源分开保存。双击 `导出场景资源包.command`（或运行 `node scripts/package-scenes.mjs`） 会在 `场景发布包/日期/` 下生成低画质版和完整版两个场景目录及各自的 ZIP；它们不包含 APP、Electron 或用户数据。此目录已排除在源码提交之外。

上传场景资源时选择这里的两个 ZIP。解压后文件夹内直接包含 scene.json、models、textures、sounds；scene.config.json 的 sceneFolder 应指向解压后的文件夹。

Release 留给自行打包的应用测试产物，场景资源发布不使用 Release 目录。默认应用打包仍使用低画质，应用打包由用户自行执行。
