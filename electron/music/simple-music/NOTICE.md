# Simple Music v2.7.0

The JavaScript modules in this directory are derived from the TypeScript sources
in [Simple Music v2.7.0](https://github.com/Yyyangshenghao/simple-music/tree/v2.7.0/server/lib)
by yshAM and contributors. They were transpiled to JavaScript for Electron
and local module paths were adjusted. They are licensed under GPL-3.0-only.
See LICENSE and the linked upstream tag for the corresponding original sources.

The NetEase adapter uses NeteaseCloudMusicApi, the same MIT-licensed API library
used by [YesPlayMusic](https://github.com/qier222/YesPlayMusic).
