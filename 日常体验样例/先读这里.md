# 周末书房：可直接使用的日常体验包

这套素材按一次真实使用过程组织：读书、听一张完整歌单、整理周末相册、写生活笔记。这里没有损坏文件、超大文件或兼容性压力数据。旧“测试样例”目录保留作开发回归，日常体验请用本目录。

## 先读一本真正的书

- **呐喊_完整中文本.txt**：鲁迅的完整中文作品文件，保留原始版本与授权说明；不是生成的重复段落。可以直接在当前书库导入。
- **爱丽丝梦游仙境_完整英文.pdf**：69页完整英文文件，可直接在当前书库导入。此PDF为文字版，没有插图。
- **爱丽丝_1907插图版.epub**：另一历史版本，正文含28个图像位置，包内保存55份图像资源（含缩略图与对应大图），约1.77MB；保留原始正文、插图、目录与许可。这是1907插图版，不应与前述另一版本PDF逐页对应。
- **爱丽丝_插图版_浏览器打开/19033-h.htm**：双击即可离线浏览原书图文；图片文件夹要保留在旁边。

当前项目书库仍只接受MD/TXT/PDF，暂时不能直接导入EPUB；PDF转文字也不会保留原页图片。这是现有阅读器的限制。图文版可以先在浏览器或系统电子书应用阅读，供后续图文阅读功能使用，不能把导入不支持误判为书籍损坏。

书籍大小由正文、插图数量和压缩决定，不人为补大。一本文字完整的小说只有几百KB完全正常；这次中文TXT约0.28MB，英文PDF约0.71MB，插图EPUB约1.77MB。它们都是实际内容大小，不是用空白填充出来的。

## 导入一张完整的本地歌单

进入唱片机，选择文件夹 **02_周末阅读歌单**。五首MP3属于同一专辑《周末留白》，附曲名、艺人“书房合成乐团”、曲序和内嵌封面。总时长约18分钟。

1. 清晨翻开第一页：约3分37秒
2. 窗边的茶：约3分50秒
3. 午后慢行：约3分16秒
4. 雨停之前：约3分57秒
5. 灯下的最后一章：约3分43秒

它们是程序创作的合成器乐，有旋律、和弦、低音与段落变化，不是几秒钟的测试音，也不冒充真人演奏或商业发行歌曲。听感定位是轻柔阅读背景。M3U8是供其它播放器使用的辅助歌单；当前应用选择整个文件夹，不依赖M3U8导入。

正常使用：从第2首开始播放→拖到中间→下一首→打开书库继续阅读→返回播放器。之后可以检验关闭重开是否还保留播放状态；素材是真实可解码MP3，但应用现有本地音频持久化问题仍可能影响重启后播放。

## 整理一次周末旅行

**03_旅行相册** 有三张不同画面的1536×1024 JPEG：清晨湖边、午后桥边、傍晚茶园。已写入2026年10月17—18日的拍摄日期和杭州附近坐标，按两日游顺序组织。

图片是AI生成的写实虚构场景；日期和坐标为情境设定，不是实地拍摄证据，也不声称精确对应某个真实桥位。可以整文件夹导入地球仪，确认地点、设相册封面、补旅行说明。每张都有正常元数据，不需要处理故意设置的异常。

## 把生活记录串起来

**04_生活记录** 中有“杭州周末日记”和“阅读与听歌笔记”。可将日记正文粘贴进日记本、附上湖边照片，把阅读笔记放入知识库；待办段落可以逐项加入便签。内容和书籍、相册、歌单对应，可体验从收藏到阅读、记录、回顾的完整过程。
